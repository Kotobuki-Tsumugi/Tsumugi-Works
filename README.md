# 昼迟的作品集

这里收着我写的小说、歌词、随笔，还有一些学习资料。你不需要安装任何软件，也不用懂代码，直接在这个网页上点开就能读。

## 怎么读

1. 点上方文件列表里的 **创作** 文件夹。
2. 选一个分类，比如 **小说** 或 **歌词**。
3. 点开任意一个文件，正文就会显示出来。

读完想回上一层，点页面顶部的文件夹名，或者浏览器的"后退"。

## 这里有什么

| 文件夹 | 内容 |
| - | - |
| [创作](创作) | 小说、歌词、随笔、MV 脚本，以及长篇《孤独罪》的设定与写作资料 |
| [学习](学习) | 编程入门教程、考研备考资料（需要下载到电脑上打开，见里面的说明） |

## 想存到自己电脑上

点页面右上方绿色的 **Code** 按钮，选 **Download ZIP**，下载后解压即可。

## 关于修改

你被邀请为协作者，技术上是可以修改这里的文件的。如果只是想留言或提建议，直接告诉我就好，请不要直接改文件。万一不小心改了也没关系，所有改动都有记录，可以恢复。
