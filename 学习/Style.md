## Agent 风格约束 · Claude 官方视觉语言（浅色温暖版 · 全相对单位适配）

### 一、核心理念

* **温暖优先**：暖奶油底色 + 珊瑚橙，营造“可编辑、有温度”的阅读氛围。
* **克制优雅**：少阴影，多留白；层级清晰，不花哨。
* **品牌识别**：主色珊瑚橙（`#cc785c`），辅色蓝（`#6a9bcc`）与绿（`#788c5d`）。

### 二、色彩系统（强制）

| 用途           | 色值                    | 备注           |
| :----------- | :-------------------- | :----------- |
| **页面背景**     | `#faf9f5`             | 暖奶油色，核心基调    |
| **卡片/区块背景**  | `#ffffff` 或 `#f5f4ef` | 纯白为主卡，浅暖灰为次级 |
| **主品牌色（橙）**  | `#cc785c`             | 按钮、链接、高亮     |
| **主品牌色（橙深）** | `#b56145`             | Hover、强调边框   |
| **辅色（蓝）**    | `#6a9bcc`             | 次要按钮、标签      |
| **辅色（绿）**    | `#788c5d`             | 成功状态、辅助信息    |
| **正文文字**     | `#141413`             | 深近黑          |
| **次要文字**     | `#5a5a56`             | 描述、注释        |
| **边框/分割线**   | `#e0ddd3` 或 `#cbc7bc` | 暖灰调          |

### 三、组件风格（强制）

* **卡片**：白底 + 极轻边框（`0.0625em solid #e0ddd3`）+ 极轻阴影（用 `filter: drop-shadow(0 0.0625rem 0.1875rem rgba(0,0,0,0.04))`），无深色玻璃质感。
* **标题**：使用 `#141413`，可选用渐变文字（`#cc785c` → `#d99b7a`），字号用 `clamp()` 控制（如 `clamp(1.5rem, 4vw, 3rem)`）。
* **英雄区**：径向渐变从 `#f5ede6` 到 `#faf9f5`，极淡橙色柔光（`radial-gradient` + `filter: blur(clamp(2rem, 5vw, 4rem))`）。
* **公式/代码块**：背景 `#f0eeea`（浅暖灰），左侧边框 `0.25em solid #cc785c`，字体等宽深色（`#141413`），内边距 `1.25rem 1.5rem`。
* **MathML 公式渲染（强制）**：所有 `<math>` 元素（块级和内联）必须在浅背景（`#f0eeea`）上以深近黑（`#141413`）显示，**严禁黑底白字**。`<mtext>` 内文用辅色蓝 `#6a9bcc` 或辅色绿 `#788c5d` 标注。行内公式（`<math class="inline">`）保持正文深黑色，不增加背景色。
* **公式行内代码（formula-line）**：背景 `#f0eeea`，左侧边框 `0.125em solid #cc785c`，字体等宽 `#141413`，内边距 `0.25em 0.625em`。
* **按钮**：主按钮背景 `#cc785c`，Hover 转 `#b56145`，内边距用 `0.6em 1.5em`。
* **表格**：表头背景 `#f0ede7`，行悬停 `#faf8f3`，单元格内边距 `0.75rem 1rem`。
* **侧栏/备注框**：左侧边框 `0.1875em solid #cc785c`，背景 `#f8f5ef`，内边距 `clamp(0.75rem, 1.5vw, 1.5rem)`。
* **交互反馈**：Hover 辉光用 `box-shadow: 0 0 0 0.125em rgba(204,120,92,0.2)`，过渡 `0.2s ease`。

### 四、禁用/避免事项（红线）

* ❌ 禁止深色主题（背景不低于 `#e8e3d8`）。
* ❌ 禁止紫色（`#7B61FF` 及任何衍生紫）作为主色。
* ❌ 禁止高饱和冷蓝（如 `#007aff`）作为主色调。
* ❌ 避免过度使用 emoji，装饰优先采用 SVG 图标。
* ❌ 避免大面积渐变（仅允许英雄区和标题小范围使用）。

### 五、排版与间距

* 正文字体栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`。
* 代码字体：`"JetBrains Mono", "Fira Code", monospace`。
* 行高：正文 `1.6`，标题 `1.2`。
* 间距体系：基础单位 `0.5rem`，常用边距为 `1rem` / `1.5rem` / `2rem` / `3rem`（均用 `clamp()` 包裹以获得流畅缩放）。

### 六、相对单位强制规则（🟥 硬性红线）

> 以下所有尺寸，**禁止使用** **`px`** **单位**，仅允许使用相对单位：

1. **字体大小**：全部使用 `rem`（基准 `1rem = 16px`）。例如正文 `1rem`，H3 `clamp(1.25rem, 2vw, 1.5rem)`，H1 `clamp(2rem, 5vw, 3.5rem)`。
2. **宽高**：使用 `%`、`vw`、`vh`/`dvh`、`fr`、`minmax()`。容器最大宽度用 `min(100%, 75rem)` 代替固定宽度。
3. **内边距 & 外边距**：使用 `rem` 或 `em`，优先 `clamp(最小值, 首选值, 最大值)` 实现流畅缩放。
4. **边框 & 圆角**：边框宽度用 `em`（如 `0.0625em solid...`），圆角用 `rem`（如 `clamp(0.25rem, 0.5vw, 0.75rem)`）。
5. **定位（top/right/bottom/left）**：使用 `%` 或 `vw`/`vh`。例如 `top: 5vh; left: 2.5%`。
6. **阴影/模糊半径**：模糊值用 `rem` 或 `vw`，例如 `blur(clamp(1rem, 2vw, 2.5rem))`。
7. **媒体查询断点**：全部用 `rem` 或 `em`（如 `@media (width < 48rem)`），**禁止** `px` 断点。
