二、四个常见误区，提前帮你绕开

⚠️ 零基础学习者的四大误区

✗ 误区 "我先看一遍全书，搞清楚所有概念再开始做练习"——这是最慢的方法。正确做法是边看边练，每个概念学完立刻做对应的例题。

✓ 正确 每天学完后，合上书本，在纸上默写今天学了什么。默不出来的部分就是你没真正理解的部分。

🧱 基础概念：从零讲起

下面这些术语是后续所有内容的地基。如果任何一个你不熟悉，花 10 分钟在这里搞懂，比后面反复查要快得多。

📦 变量（Variable）

就像你家的电表：读数一直在变，所以我们用一个字母"u"来代表它。

数学写法：用字母表示会变化的量，如 u(t)、i(t)、x、y。
电气对应：电压 u、电流 i 都是随时间变化的变量。

🔒 常数（Constant）

就像重力加速度 g 永远≈9.8，不会变，所以用数字固定下来。

数学写法：用数字或特定字母表示不变的量，如 π≈3.14、e≈2.72。
电气对应：电阻 R=100Ω（固定电阻）、电源电压 E=12V（稳压源）。

📐 函数（Function）

就像 ATM 机：你输入密码和金额（输入），它吐出钱（输出）。同一个输入永远对应同一个输出。

数学写法：y = f(x)，读作"y 是 x 的函数"。
电气对应：u(t) 表示"电压是时间的函数"——不同时间，电压不同。

🧩 方程（Equation）

就像一个天平：左右两边必须一样重。方程就是"等号两边的值相等"。

数学写法：2x + 3 = 7（求 x 使等式成立）。
电气对应：欧姆定律 I=U/R 本身就是一个方程——已知两个量，求第三个。

📏 指数（Exponent）

就像细菌分裂：每过一代数量翻倍。2¹⁰ = 1024 比 2×10 大得多——这就是指数的威力。

数学写法：aⁿ 表示"a 自乘 n 次"。2³ = 2×2×2 = 8。
电气对应：电容充电曲线 u(t) = E(1−e^(−t/RC)) 中的 e^(−t/RC)。

📋 对数（Logarithm）

如果指数是"翻倍的魔法"，对数就是"这个魔法重复了多少次"。10³=1000 → 反过来 log₁₀(1000)=3。

数学写法：loga(b) = c 表示 ac = b。
电气对应：分贝 dB = 10·log₁₀(P/P₀)，把巨大的功率比压缩成小数。

🔄 弧度制（Radian）

角度制就像用"步数"量路，弧度制就像用"轮子滚过的距离"量路——弧度更自然，因为圆周长 = 2πr。

数学写法：360° = 2π rad，180° = π rad，90° = π/2 rad。
电气对应：正弦波一个完整周期 = 2π 弧度 = 360°。

🔢 虚数单位 j

数学中 i²=−1 没有"正常"解，但电气里我们叫它 j（因为 i 已经表示电流）。它不是"假的"，而是"垂直方向的数"。

数学写法：j = √(−1)，j² = −1。
电气对应：复数 z = a + jb，用来同时表示交流电的幅值和相位。

如果你觉得上面某个概念已经熟悉，可以跳过；但如果你发现某个术语完全没听过，建议停下来，花 5 分钟在搜索框里搜一下它的"定义"，确保基础扎实再往下看。

📅 第 1 周：初等数学补强 + 函数与极限

Day 1–3 · 方程、三角函数、指数对数 基础

Day 1：方程与不等式

解方程是电气计算的第一基本功。欧姆定律

I=UR

本身就是一个一元一次方程。

// 一元二次方程求根公式 x = −b±b2−4ac 2a

判别式：Δ = b² − 4ac。Δ>0 → 两个不等实根；Δ=0 → 一个重根；Δ<0 → 无实根

🔌 电气视角

RLC 串联电路的谐振频率公式推导，本质就是解一个关于角频率 ω 的一元二次方程。

Day 2：三角函数

// 交流电压的标准表达式 u(t) = 2 U sin(ωt+φ)

U = 有效值； ω = 角频率 = 2πf（工频 f=50Hz → ω≈314 rad/s）； φ = 初相角

Day 3：指数与对数

// 指数运算法则 同底数相乘：am+n=am⋅an 同底数相除：aman=am−n 幂的乘方：(am)n=amn
// 工程常用：分贝（dB） 功率比： PdB=10⋅log10(PP0) 电压比： VdB=20⋅log10(VV0)
🔌 电气视角

分贝（dB）是电气工程师的语言。它把"倍乘关系"变成"加减关系"，串多个器件时只要把 dB 值相加即可。

📝 小测验：三角函数与电气

我国工频交流电的频率为 50 Hz，其角频率 ω 约为多少 rad/s？

✅ 正确答案：B。ω = 2πf = 2 × 3.1416 × 50 ≈ 314 rad/s。
Day 4–7 · 函数、极限与两个重要极限 进阶

Day 4：函数概念

函数就是"输入→输出"的规则。在电气中，电压是时间的函数 u(t)，电流是时间的函数 i(t)。

函数的关键属性

  • 定义域：允许输入的范围（如电阻 R>0）
  • 值域：输出的取值范围
  • 单调性：增大还是减小
  • 奇偶性：偶函数→波形关于 y 轴对称

电气中的常见函数

  • u(t) = Uₘ sin(ωt) — 正弦函数
  • u(t) = E(1 − e−t/RC) — 指数增长
  • i = k·eqV/kT — 二极管方程

Day 5–6：两个重要极限

// 两个必须掌握的重要极限 极限 ① limx→0 sinx =1 极限 ② limx→∞ (1+1x)x =e≈2.71828

电气意义： 极限① → 小角度近似 sinθ≈θ（小信号分析）； 极限② → 自然常数 e 的来源（电容充放电 e−t/RC）

🔌 电气视角

电容充电公式 u(t)=E(1−e−tRC)，当 t→∞ 时 u→E（充满）。时间常数 τ=RC 决定充电快慢。

📝 小测验：极限与电路

RC 串联电路中，电容电压 u(t)=E(1−e−tRC)。当 t→∞ 时，电容电压趋于？

✅ 正确答案：C。当 t→∞ 时 e−t/RC→0，所以 u(t)→E。
📝 例题精解：解一个与电气相关的方程
已知一个串联电路的总电阻 R总 = R1 + R2，其中 R1 = 2R2，且 R总 = 60Ω。求 R1 和 R2。
1
列出已知条件： R1 + R2 = 60　且　R1 = 2R2 💡 把电路条件翻译成数学方程，这是最重要的一步。
2
把 R1 = 2R2 代入第一个方程： 2R2 + R2 = 60 💡 这就是"代入消元法"——用第二个方程消掉 R1，只留下 R2。
3
合并同类项： 3R2 = 60 💡 2R2 + R2 就是 2 个 R2 加上 1 个 R2，一共 3 个。
4
两边同除以 3： R2 = 60 ÷ 3 = 20Ω
5
回代求 R1： R1 = 2R2 = 2 × 20 = 40Ω
✅ 验证：R1 + R2 = 40 + 20 = 60Ω ✓　且 R1 = 2 × R2 = 2 × 20 = 40 ✓

⚠️ 常见错误 & 避坑指南

✗ 错
把弧度当角度：看到"50Hz"就直接用角度算 sin(50)，忘记 ω = 2πf。
✓ 对
先算 ω = 2πf = 2π×50 ≈ 314 rad/s，再用弧度制算 sin(ωt)。
✗ 错
认为 log(a+b) = log(a) + log(b)。（就像认为"2+3 的 log 等于 2 的 log 加 3 的 log"——不对！）
✓ 对
log 只对乘除有"展开"性质：log(a·b) = log(a) + log(b)。
✗ 错
把 sin²x 当成 sin(x²)。（sin²x = (sinx)²，是先把 x 求正弦，再平方）
✗ 错
算判别式 Δ = b²−4ac 时，把 c 的符号搞反。
✓ 对
写方程时先把所有项移到一边，变成标准形式 ax²+bx+c=0，再套公式。

📅 第 2 周：导数与微分

Day 1–7 · 从变化率到导数应用 核心

Day 1：导数的物理意义

导数 = 变化率。在电气中，它无处不在——

// 导数的定义 f′(x) = limΔx→0 f(x+Δx)−f(x)Δx

几何意义：曲线在某点的切线斜率　物理意义：瞬时变化率

// ⚡ 电气中最重要的导数关系 电容电流： i=C⋅dudt 电感电压： u=L⋅didt 电磁感应： ε=−dΦdt
🔌 电气视角

电容"通交流、隔直流"：直流电压下 du/dt=0，所以 i=0，电容相当于开路。交流电压下 du/dt 不断变化，电流随之变化，电容"导通"。

📝 小测验：导数与电容

已知电容两端电压 u(t)=10sin(100t) V，电容 C=100μF。则流过电容的电流 i(t) 为？

✅ 正确答案：B。i = C·du/dt = 100×10⁻⁶ × 10×100×cos(100t) = 0.1 cos(100t) A。
📝 例题精解：求电容电流
已知一个电容 C = 50μF，其两端电压 u(t) = 6sin(100t + 30°) V。求流过电容的电流 i(t)。
1
写出公式：电容电流 = 电容 × 电压的变化率 i(t) = C · du/dt 💡 这是电容的基本方程。导数 du/dt 就是"电压变化得多快"。
2
对 u(t) = 6sin(100t + 30°) 求导： du/dt = 6 · cos(100t + 30°) · 100 = 600cos(100t + 30°) 💡 这里用了链式法则：外层是 sin()，内层是 (100t+30°)。sin 的导数是 cos，再乘以内层的导数 100。
3
乘以 C（注意 50μF = 50×10⁻⁶ F）： i(t) = 50×10⁻⁶ × 600cos(100t + 30°) = 0.03cos(100t + 30°) A
✅ i(t) = 30cos(100t + 30°) mA。注意电流比电压超前 90°（cos 比 sin 超前 90°），这正是电容的特性。

⚠️ 常见错误 & 避坑指南

✗ 错
对 sin(ωt) 求导时忘记链式法则：直接写 cos(ωt)，漏掉了 ω。
✓ 对
[sin(ωt)]' = cos(ωt) · ω。先对 sin 求导得 cos，再乘以内层 ωt 的导数 ω。
✗ 错
把 (uv)' 当成 u'v'（两个函数的导数相乘）。
✓ 对
乘积法则：(uv)' = u'v + uv'。注意中间的"+"号。
✗ 错
把 dy/dx 当成一个分数随意拆开：dy/dx = (dy)/(dx) 有时可行，但绝不能随意约分。
✗ 错
商法则忘记负号：(f/g)' = (f'g − fg')/g²，分子是"f'g 减 fg'"。
✓ 对
记口诀"上导下不导，减下导上不导，分母下下平方"—— (f/g)' = (f'g − fg')/g²。

📅 第 3 周：积分与常微分方程入门

Day 1–7 · 从面积到电路暂态 核心

Day 1–2：不定积分

积分是求导的逆运算。如果 f'(x) = g(x)，那么 ∫g(x)dx = f(x) + C。

// 基本积分公式表 幂函数：∫xndx=xn+1n+1+C (n≠−1) 倒数：∫1xdx=ln|x|+C 指数：∫exdx=ex+C 正弦：∫sinxdx=−cosx+C 余弦：∫cosxdx=sinx+C

电气注意：∫ e−t/τ dt = −τ·e−t/τ + C（RC 电路暂态分析关键公式！）

Day 3：换元积分 & 分部积分

第一类换元（凑微分）

把 ∫f(g(x))·g'(x)dx 看作 ∫f(u)du（令 u=g(x)）。

// 例题 ∫2x⋅cos(x2)dx

令 u=x²,　du=2x·dx

=∫cos(u)du=sin(u)+C=sin(x2)+C

分部积分法

// 公式 ∫u⋅dv=uv−∫v⋅du

口诀："反对幂三指" — 反三角>对数>幂>三角>指数（选择 u 的优先级）

📝 例题精解：换元积分 + 定积分
计算 ∫₀^π sin²x dx。这是求正弦平方在一个周期内"平均面积"的问题。
1
直接用积分表找不到 sin²x。用三角恒等式降幂： sin²x = (1 − cos2x) / 2 💡 这是"凑"的技巧。我们把它变成 1/2 减去 cos2x/2，这两个都有积分公式。
2
代入积分： ∫₀^π sin²x dx = ½∫₀^π (1 − cos2x) dx
3
逐项积分： = ½ [x − (1/2)sin2x]₀^π 💡 ∫1 dx = x；∫cos2x dx = (1/2)sin2x（链式法则反过来，除以内层导数）。
4
代入上下限： = ½ [(π − 0) − (0 − 0)] = π/2
✅ ∫₀^π sin²x dx = π/2 ≈ 1.57。这说明正弦平方的"平均面积"是 π/2，这个结果在功率计算中经常出现。

⚠️ 常见错误 & 避坑指南

✗ 错
不定积分忘记加 "+C"。∫f(x)dx = F(x) 不完整，应该是 F(x)+C。
✗ 错
把 ∫f(u)·du 当成 ∫f(u)·du 直接套公式，漏掉链式法则需要除以"内层的导数"。
✓ 对
换元时，u=g(x)，du=g'(x)dx。如果 dx 前面没有 g'(x)，需要先"凑"出来。
✗ 错
分部积分选 u 时乱选，导致越积越复杂。
✓ 对
按"反对幂三指"优先级选 u：反三角 > 对数 > 幂 > 三角 > 指数。
✗ 错
解微分方程时忘记代入初始条件确定常数 A。
✓ 对
先求通解 u(t) = E + A·e^(−t/RC)，再代入 t=0, u=0 得 A=−E。

三种积分变换的"地图"

变换从 → 到核心用途电气关联

傅里叶变换

// 定义 F(ω) = ∫−∞∞ f(t) ⋅ e−jωt dt

物理意义：把任意信号分解为无数个不同频率的正弦波之和

拉普拉斯变换

// 定义 F(s) = ∫0∞ f(t) ⋅ e−st dt （ s=σ+jω ）

核心优势：微分→乘以s；积分→除以s。把微分方程变成代数方程！

📝 例题精解：相量法计算 RLC 串联电路总阻抗
一个 RLC 串联电路：R=3Ω，L=0.01H，C=100μF，信号频率 f=50Hz。求总阻抗 Z。
1
先算角频率 ω： ω = 2πf = 2π×50 ≈ 314 rad/s
2
分别计算三种阻抗： ZR = 3　|　ZL = jωL = j×314×0.01 = j3.14　|　ZC = 1/(jωC) = 1/(j×314×100×10⁻⁶) ≈ −j31.8 💡 电感阻抗是正虚部（+j），电容阻抗是负虚部（−j）。这是最关键的区分！
3
串联总阻抗 = 各阻抗之和： Z = ZR + ZL + ZC = 3 + j3.14 + (−j31.8) = 3 − j28.66
4
算模值（幅值）： |Z| = √(3² + 28.66²) ≈ 28.8Ω 💡 3²=9，28.66²≈821，加起来≈830，开根号≈28.8。
5
算相位角： φ = arctan(−28.66/3) ≈ −84° 💡 相位角为负，说明电容效应占主导，电流超前电压（容性电路）。
✅ Z ≈ 28.8∠−84° Ω。即阻抗大小约 28.8Ω，电流超前电压约 84°。

⚠️ 常见错误 & 避坑指南

✗ 错
矩阵乘法搞成"对应元素相乘"。Cij 不是 Aij×Bij，而是"行×列"的求和。
✓ 对
Cij = Σ Aik·Bkj。第一矩阵的第 i 行，乘以第二矩阵的第 j 列，对应元素相乘再求和。
✗ 错
复数加减时用指数形式（e^(jφ)）。这样很难算。
✓ 对
加减用代数形式（a+jb）：实部加实部，虚部加虚部。乘除才用指数形式。
✗ 错
相量运算时忘了前提是"ω 相同"。只有同频率的正弦量才能用相量相加。
✓ 对
先确认所有相量是同一 ω，再相加减。不同频率的信号不能用相量法合并。
✗ 错
把拉普拉斯变换的积分下限从 0 写成 −∞（那是傅里叶变换的范围）。
✓ 对
拉普拉斯变换从 0 到 ∞（因果系统），傅里叶变换从 −∞ 到 ∞（全时间轴）。
