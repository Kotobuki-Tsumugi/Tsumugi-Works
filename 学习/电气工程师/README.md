## 使用方式

| 场景 | 打开 |
|---|---|
| 今天该做什么、倒计时、专注计时、本周时长 | `华电电气考研备考计划.html`（默认 `#today`） |
| 15 个月甘特、31 个双周块（点卡片开详情抽屉：勾任务、写笔记、←/→ 切块） | `#route`，`#route/now` 直接定位本块 |
| 打卡清单（全部 / 未完成 / 紧急 筛选） | `#check` |
| 考试事实、周计划、目标分、时间轴、待确认项、来源 | `#docs`，`#docs/<锚点>` 定位小节 |
| 核对考试范围与题型 | `考纲\` 内的官方文件 |

双击即可离线使用（file://，无外部依赖）。旧锚点（`#p1`、`#checklist`、`#facts` 等）自动映射到对应视图。

- **快捷键**：`Ctrl/⌘+K` 或 `/` 打开命令面板（搜视图、操作、阶段、双周块、打卡项、资料小节），`,` 打开设置，`1`–`4` 切换视图，`Esc` 关闭
- **设置**：主题（跟随系统/深色/浅色）、动效（跟随系统/完整/减少）、悬停卡片开关、默认打开视图
- **悬停卡片**：鼠标停在双周块、甘特横道、节点、阶段条、时长柱上显示详情（键盘聚焦同样可见）
- **安装为应用 / 离线缓存**：需通过 http(s) 访问，例如在本目录运行 `python -m http.server` 后打开 `http://localhost:8000/华电电气考研备考计划.html`；file:// 双击不受影响，只是不启用这两项

- **学习中心**：今天视图「今日复习」卡汇总词汇 / 数二公式 / 831 / 错题本的今日待办，点「开始」或「学习中心」进入全屏弹层（命令面板也可搜「学习中心」「数二真题」「错题本」）
  - 公式卡（数二、831）：正面 科目·章节 + 标题，翻面看公式、条件、要点、用法、易错，例题折叠；`1/2/3` 不会/模糊/会（SM-2）。章节按路线块日期解锁，每组每天新卡默认 10（可调），卡组页可「提前解锁」下一章
  - 数二真题：按年整套（可选 3 小时计时，逐题看答案，自评 对/半对/错，满分非 150 的卷按 150 折算）或按章节刷（全部/未做/在错题本）。选择题点选项自动判分。章节由构建时关键词自动归类，可在题头下拉改（存本机）
  - 错题本：自评 错/半对 的题自动加入，可写一句错因；到期按 SM-2 复习，连续 3 次「会」后移出
- **背词**：今日复习卡的「英二词汇」行（或命令面板「打开词汇」）进入全屏闪卡。到期复习在前，今日新词按频次补足（默认每天 50）；`空格` 翻面、`1/2/3` 不认识/模糊/认识、`R` 发音（浏览器 TTS）、`U` 撤销。「不认识」本轮隔几张再出现。词表按频次分 22 个 Unit，弹层顶部显示「当前 Unit · 计划应在 Unit」。当天复习清零且新词达标即完成：首次完成自动勾「英语词汇开始每日打卡」，连续 14 天自动勾「词汇连续打卡 14 天」。学习进度按真实日期计算，不受 `?today=` 影响
- **重建公式卡 / 真题**：`python ee831/build_ee831.py`（改完 cards.md 后运行）；`python math2/build_math2.py -v`（下载到 `math2/.cache/`，逐卷打印诊断）。两者都支持 `--export-only`、`--no-check`，需要 node 才做 KaTeX 校验。卡片按 id 存进度，重建后记录保留
- **重建词库**：在本目录运行 `python vocab/build_vocab.py`（自动下载 ECDICT 到 `vocab/.cache/`），或 `--csv 路径` 使用已下载的 `ecdict.csv`；`--export-only` 只从 vocab.db 重新导出 JS。词条按单词存进度，重建词库后已背记录保留
- **模拟日期**：地址后加 `?today=2027-03-10`，检查今日线、本块高亮与截止着色（顶栏显示黄色标记）
- **存储**（localStorage，按文件路径隔离）：`ncepu-ee-plan-v1` 打卡 `{"组-项":1}`（与旧版兼容）、`ncepu-ee-blocks-v1` 块任务、`ncepu-ee-notes-v1` 块笔记、`ncepu-ee-time-v1` 每日学习分钟、`ncepu-ee-timer-v1` 计时器、`ncepu-ee-path-fold` 折叠已过、`ncepu-ee-settings-v1` 界面设置、`ncepu-ee-vocab-v1` 背词进度 `{cards:{词:{e,r,i,d,l}}, days:{日期:{n,rv,done}}, cfg}`、`ncepu-ee-learn-v1` 学习中心 `{decks, days, grades, attempts, ch, wrong}`（后两者不含在导出备份中）
- **备份**：打卡视图「导出」得到 `{key, exported, data, blocks, notes, time}` JSON；「导入」兼容旧版只含打卡的文件，导入与重置都可在提示条里撤销
- **打印**：顶栏打印按钮按 今天 → 路线 → 打卡 → 资料 顺序分页输出
