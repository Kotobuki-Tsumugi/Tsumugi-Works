# 学习

这里的东西会动。
有动画，能背单词，能打卡。
所以在 GitHub 上只看得到它的骨头，
看不到它活着的样子。

## 怎么打开

1. 回到首页，点绿色的 **Code**，选 **Download ZIP**。
2. 解压。
3. 进「学习」，双击下面的文件，浏览器会打开它。

| 是什么 | 双击这个 |
| - | - |
| Go 入门指南 | `编程语言入门/Go/Go入门指南.html` |
| HTML 入门教程 | `编程语言入门/HTML/HTML入门教程.html` |
| 华电电气考研备考计划 | `电气工程师/华电电气考研备考计划.html` |

两份入门教程的动画和代码高亮要联网才有。
备考计划不用联网，双击就能用。
