# 学习

这里的资料是可以互动的网页（带动画、代码高亮、背单词、打卡等功能）。GitHub 网页上只会显示它们的源代码，**不能直接在这里看**。

## 怎么打开

1. 回到仓库首页，点绿色的 **Code** 按钮，选 **Download ZIP**。
2. 解压下载的文件。
3. 进入 `学习` 文件夹，双击下面列出的 `.html` 文件，它会在浏览器里打开。

| 资料 | 打开这个文件 |
| - | - |
| Go 入门指南 | `编程语言入门/Go/Go入门指南.html` |
| HTML 入门教程 | `编程语言入门/HTML/HTML入门教程.html` |
| 华电电气考研备考计划 | `电气工程师/华电电气考研备考计划.html` |

编程入门教程的动画和代码高亮需要联网才能显示。考研备考计划的"离线使用"功能只有通过网址访问时才可用，双击打开时其他功能正常。
