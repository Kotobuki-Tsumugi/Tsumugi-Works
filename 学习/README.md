## 推荐使用方式

1. 先阅读页面开头的学习目标和先修要求。
2. 每节按“概念 → 示例 → 练习 → 自测”的顺序完成，不只浏览代码。
3. 把错题、运行结果和仍然不理解的术语记录到自己的笔记中。
4. 电气工程章节优先手算，再用仿真工具验证；Go 和 Web 章节优先复制示例并做一次改动。

## 维护约定

- 新章节必须在本文件登记，并注明先修章节、目标和完成标准。
- 代码示例应注明适用版本；外部资源应记录来源和访问日期。
- 修改 HTML 后运行静态检查：

  ```powershell
  powershell -ExecutionPolicy Bypass -File study/tools/check-study.ps1
  ```

- 检查脚本会报告标签闭合、重复 ID、失效的页内锚点和外部链接数量；它不替代浏览器中的视觉和交互测试。
