第二章

学习前的准备：先认识网页文件

很多人第一次学 HTML 不是被代码难住，而是卡在“我该在哪里写、怎么写、怎么打开”。这一章不写复杂代码，只做一件事：亲手创建并打开你的第一个网页文件。

本章目标

你能独立创建文件夹、新建 HTML 文件、正确保存，并在浏览器里看到自己的页面。

先记住一个最重要的概念：网页就是一个文本文件

你在浏览器里看到的网页，本质上是一个用普通文字写成的文件。这个文件里写的是 HTML 代码，浏览器读完代码后，把它渲染成漂亮的页面。

所以你需要的东西只有三样：一个能写文字的程序、一个能保存文件的位置、一个能打开网页的浏览器。

文字编辑器

推荐 VS Code，免费且适合新手。如果暂时不想安装，Windows 自带的“记事本”也能完成今天的所有练习。

浏览器

Edge、Chrome、Firefox 都可以。今天只需要用它打开文件，不需要安装服务器或数据库。

一个文件夹

建议在桌面上新建一个叫 my-first-page 的文件夹，以后的练习都放进去。

跟着做：从空白文件到第一个网页

第一步：新建一个文件夹

在桌面点击右键，选择“新建文件夹”，命名为 my-first-page。每个小练习单独一个文件夹，以后找文件会非常方便。

第二步：打开文本编辑器

打开 VS Code，然后选择“打开文件夹”，选中刚才创建的 my-first-page。如果是记事本，直接打开一个空白文档即可。

第三步：新建一个文件

在 VS Code 里点击“新建文件”，输入下面的内容。不要急着理解，先把每一个字符原样打出来。

index.html 
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>我的第一个网页</title>
  </head>
  <body>
    <h1>你好，世界！</h1>
  </body>
</html>
第四步：用正确的名字保存

保存时把文件名写为 index.html，一定不要漏掉 .html 这三个字母。后缀决定了浏览器要不要把它当网页打开。

第五步：用浏览器打开

打开刚才的文件夹，双击 index.html。如果浏览器没有自动打开，可以右键这个文件，选择“打开方式”，再选择 Chrome 或 Edge。

第六步：看到“你好，世界！”

页面里出现“你好，世界！”就说明你成功了。浏览器标签页上还会显示“我的第一个网页”，那是 <title> 的作用。

为什么文件后缀这么重要？

Windows 默认可能不显示文件后缀。如果文件实际叫 index.html.txt，浏览器只会把它当成普通文本打开，页面就不会渲染。

文件名 是什么 浏览器打开后
index.html 正确的网页文件 显示渲染后的页面
index.html.txt 被当成纯文本文件 显示一串代码文字
index.txt 普通文本文件 显示文字，不会渲染

如果你在 Windows 的文件夹里看不到后缀，可以这样打开：在文件夹顶部点击“查看”，勾选“文件扩展名”。之后所有文件的后缀都会显示出来。

  3. 保存为 index.html，确认后缀不是 .txt。
  4. 用浏览器打开，确认能看到“你好，世界！”。
  5. 把标题改成你自己的名字，保存后刷新浏览器，再观察一次变化。

第三章

HTML 是什么？

HTML 的全称是 HyperText Markup Language，中文叫“超文本标记语言”。你可以把它理解成网页的骨架：哪些地方是标题、哪些地方是段落、哪里放图片、哪里放链接，都由 HTML 决定。

HTML 不是编程语言，它不会帮你计算，也不会自己“做决定”。它更像一份结构说明书：你把内容用一对对标签包起来，浏览器读到这份说明书，就知道该怎样把页面画出来。

本章目标

理解“标签”“元素”“属性”三个词，并看懂你的第一个 HTML 文件。

标签

HTML 使用尖括号写成的小标记，例如 <p>。大多数标签成对出现，像 <p>文字</p>，前一个是开始标签，后一个是结束标签。

元素

开始标签、内容、结束标签合在一起，叫做一个“元素”。元素是网页结构的基本积木。

属性

标签还可以带属性，用来补充信息。例如 <a href="page.html">链接</a> 里的 href 就告诉浏览器链接到哪里。

浏览器

Chrome、Edge、Safari、Firefox 都叫浏览器。它们的任务之一，就是读取 HTML 文件，并把骨架渲染成你看到的网页。

网页是怎么被浏览器画出来的？

你可以把整个过程想成“读菜谱做菜”：HTML 文件是菜谱，浏览器是厨师。浏览器从上到下阅读 HTML，把标题、段落、图片、链接放进对应的位置，最后呈现给你一个完整的页面。

file:///C:/my-first-page/index.html
你好，世界！

这是我用 HTML 写出的第一行文字。

写 HTML 需要准备什么？

一个文本编辑器

记事本也可以，但更推荐 VS Code。它免费、轻量，还能高亮标签、自动补全，写起来会轻松很多。

一个浏览器

电脑上已经自带的 Chrome、Edge 或 Safari 都可以。你不需要先安装任何服务器软件。

一个文件夹

建议为每个练习单独建一个文件夹，例如 my-first-page，把 HTML、图片、CSS 都放在里面，路径会更好管理。

你的第一个 HTML 文件

新建一个文件，把下面的内容粘贴进去，保存为 index.html，然后用浏览器打开。你会看到“你好，世界！”。

index.html 
<!DOCTYPE html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8">
    <title>我的第一个网页</title>
  </head>
  <body>
    <h1>你好，世界！</h1>
    <p>这是我用 HTML 写出的第一行文字。</p>
  </body>
</html>
先不用急着理解每一行。下一步我们会把骨架拆开，一行一行讲清楚。

把第一个文件拆开看

第 1 行：<!DOCTYPE html>

它告诉浏览器：“请按 HTML5 的标准来读这个文件。”这一行没有配对结束标签，只需要原样放在最上面。

<html lang="zh-CN"> 与 </html>

这是整个页面的“大盒子”，所有其他内容都写在它里面。lang="zh-CN" 表示页面主要使用简体中文。

<head> 与 </head>

这是页面的“说明区”，放浏览器和搜索引擎需要的页面信息。其中 title 会显示在浏览器标签页上，但不会显示在网页正文区域。

<body> 与 </body>

这是页面的“前台区”，用户能看到的文字、图片、按钮全部放在这里。

<h1> 与 <p>

h1 是一级标题，p 是段落。它们都写在 body 里，因为它们是用户能看到的内容。

标签、元素、属性的关系

“标签”是尖括号里的标记，例如 <p>。“元素”是“开始标签 + 内容 + 结束标签”的完整组合。“属性”是写在开始标签里的附加说明。

术语 例子 怎么理解
标签 <a> 一段标记，用来告诉浏览器这里是什么类型的内容
元素 <a>链接</a> 完整的“包装”，包括标签、内容和结束标签
属性 <a href="page.html">链接</a> 写在开始标签里，补充这个元素的额外信息

  4. 回到你自己的 index.html，找出页面上的标题和段落各用了什么标签。
如果你看到的源码是一长串挤在一行的代码，别慌：很多现代网站会先压缩或编译再发布。回到你自己的小页面观察即可，这里只需要熟悉 body、h1、p 这些基础标签。

第四章

网页的基本骨架

几乎所有 HTML 页面都有同一个骨架。只要记住这四层结构，你以后看任何网页源码都不会陌生。

本章目标

能默写出一个 HTML 文件的基本骨架，并知道每一部分分别负责什么。

<!DOCTYPE html> 告诉浏览器：这是一个 HTML5 文档
<html lang="zh-CN"> 整个页面的根元素
  <head> 给浏览器和搜索引擎看的“后台信息”
    <meta charset="UTF-8"> 指定文字编码
    <title>...浏览器标签页上显示的标题
  <body> 页面上真正显示给用户的内容
    <h1>... 一级标题
    <p>... 段落

<!DOCTYPE html>

它不是标签，而是一个声明，放在文件第一行。它告诉浏览器：“请按 HTML5 的标准来理解这个文件。”

<html>

它是页面最外层的根元素。所有其他内容都写在它里面。lang="zh-CN" 表示页面主要语言是简体中文。

<head>

里面放页面本身的元信息：标题、编码、CSS、描述等。用户在页面上看不到这些，但它们对浏览器非常重要。

<body>

用户能看到的文字、图片、按钮、表单，全部放在 <body> 里。它是页面的“主体区域”。

meta 标签有什么用？

<meta> 负责给页面补充说明。最常见的两个写法是：

head 中的 meta 
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
  • charset="UTF-8" 让中文正确显示。漏掉它，中文很容易变成乱码。
  • viewport 让页面在手机上按屏幕宽度显示，是移动端页面必备的一行。
记忆口诀：声明在最上，head 放信息，body 放内容，html 包全部。

head 里还能放什么？

head 是“后台信息区”。除了 title，你还会经常看到下面这些内容：

写法 作用
<meta charset="UTF-8"> 让中文正常显示，不会变成乱码
<meta name="viewport" ...> 让页面在手机上按屏幕宽度显示
<meta name="description" ...> 给搜索引擎一段页面简介
<link rel="stylesheet" href="style.css"> 引入外部 CSS 文件

为什么 body 里的内容才会显示？

浏览器的规则很简单：head 里的信息是“关于页面的说明”，body 里的内容是“要展示给用户的东西”。所以标题、段落、图片、按钮都要放进 body。

第五章

最常用的 HTML 标签

你不需要一次背完所有标签。下面这些是最常用的，先认识它们，用的时候回来查就行。

本章目标

能认出一个网页里最常见的标签，并知道标题、段落、列表、链接、图片分别用什么写。

读标签的万能方法

看到一个不认识的标签，先做三件事：看它的名字、看它包住什么内容、看它有没有属性。例如 <a href="about.html">关于我</a>：名字是 a，代表链接；包住的内容是“关于我”；属性 href 告诉浏览器跳到哪里。

标题与文字

<h1> ~ <h6>
标题

从大到小共六级。一个页面通常只有一个 h1，用来表示最重要的标题。

<h1>一级标题</h1>
<p>
段落

一段文字。浏览器会自动在段落前后留出一点间距。

<p>这是段落。</p>
<strong>
加粗

表示重要内容，浏览器默认显示为加粗。

<strong>重要文字</strong>
<em>
强调

表示需要强调的内容，浏览器默认显示为斜体。

<em>需要强调</em>
<mark>
标记

像荧光笔一样标出文字，默认带黄色背景。

<mark>重点内容</mark>
<br>
换行

在段落内手动换行。它是少数不需要结束标签的标签。

第一行<br>第二行
<hr>
分隔线

画一条水平线，用来分隔不同内容区块。

<hr>
<blockquote>
引用

表示一段较长引用，浏览器默认会缩进。

<blockquote>引文</blockquote>

链接与图片

<a>
链接

href 写目标地址，target="_blank" rel="noopener" 可在新标签页打开。

<a href="https://example.com">点我</a>
<img>
图片

src 写图片位置，alt 写图片说明，方便屏幕阅读器和图片加载失败时使用。

<img src="cat.jpg" alt="一只猫">
<figure>
图文组合

把图片和说明包在一起，说明文字用 <figcaption>。

<figure><img src="a.jpg"><figcaption>说明</figcaption></figure>

列表

<ul> + <li>
无序列表

每一项前面默认显示圆点，适合清单、菜单、功能列表。

<ul><li>苹果</li></ul>
<ol> + <li>
有序列表

每一项前面显示数字，适合步骤、排名。

<ol><li>第一步</li></ol>
<dl> + <dt> + <dd>
定义列表

适合“术语 + 解释”的成对内容。

<dt>HTML</dt><dd>标记语言</dd>

结构容器

<div>
区块容器

把一组内容包起来，通常配合 class 或 id 使用。它默认独占一行。

<div>一组内容</div>
<span>
行内容器

只包住一行内的一小段文字，不影响段落换行。

<span>小范围</span>
<!-- -->
注释

写给人的说明，浏览器不会显示。写复杂代码时非常有用。

<!-- 这是注释 -->
<code> + <pre>
代码

<code> 显示行内代码，<pre> 保留空格和换行。

<pre><code>代码</code></pre>

表格

表格由 <table>、<tr>（行）、<th>（表头）、<td>（单元格）组成。

table.html 
<table>
  <tr>
    <th>课程</th>
    <th>难度</th>
  </tr>
  <tr>
    <td>HTML</td>
    <td>简单</td>
  </tr>
  <tr>
    <td>CSS</td>
    <td>中等</td>
  </tr>
</table>

合并单元格：colspan 与 rowspan

想让某个单元格横跨多列，用 colspan；想竖着跨多行，用 rowspan。下面的表格里，“课程表”横跨了两列，“午休”竖着跨了两行。

table.html 
<table>
  <tr>
    <th colspan="2">课程表</th>
  </tr>
  <tr>
    <td>上午</td>
    <td>HTML</td>
  </tr>
  <tr>
    <td rowspan="2">中午</td>
    <td>12:00 吃饭</td>
  </tr>
  <tr>
    <td>13:00 午休</td>
  </tr>
</table>
想偷懒也没关系：每个标签都可以“按需查询”。做得多了，常用标签自然就记住了。

第六章

属性：给标签补充信息

属性写在开始标签里，用来补充标签的行为或样式信息。最常见的格式是 属性名="属性值"。

本章目标

能看懂常见属性，知道 id、class、href、src 分别用来干什么，并理解相对路径和绝对路径。

属性 通常用在 作用 示例
href <a> 链接要跳转到的地址 href="about.html"
src <img>, <video>, <audio> 图片或媒体文件的位置 src="photo.png"
alt <img> 图片无法显示时的替代文字，也帮助无障碍阅读 alt="夕阳下的海"
id 任意标签 给元素一个唯一名字，常用于锚点跳转和 JavaScript id="header"
class 任意标签 给多个元素分组，方便统一加样式 class="card"
style 任意标签 直接写一点内联 CSS，适合临时调试 style="color: red;"
title 任意标签 鼠标悬停时显示的小提示 title="更多说明"
target <a>, <form> 在哪里打开链接或提交结果 target="_blank" rel="noopener"
data-* 任意标签 给元素保存自定义数据，通常给 JavaScript 使用 data-count="3"

data-*：给元素贴标签

data-* 是一组特殊属性：名字以 data- 开头，后面随便起名，用来在标签上保存自定义数据。JavaScript 里通过 dataset 读取，横线会自动转成驼峰：data-count 对应 dataset.count。

index.html

  btn.addEventListener("click", function () {
    btn.textContent = "次数：" + btn.dataset.count;
  });
</script>
这段代码里的 document.querySelector、addEventListener 和 dataset 属于 JavaScript 内容，第 17 章会系统学习。本章你只需要知道：data-* 可以在标签上保存自定义数据，后续能用 JS 读取。

其他常用全局属性还有 lang（语言）、hidden（隐藏元素）、tabindex（键盘顺序）。它们几乎可以用在任意标签上。

路径：相对路径和绝对路径

写 src 或 href 时，最常出错的是路径。你只需要记两种：

相对路径

以当前文件为起点去找目标文件。例如 HTML 在根目录，图片在 images 文件夹里，就写 images/cat.jpg。

../ 表示“往上一层目录”。

绝对路径

以网站根目录或完整网址为起点。例如 /images/logo.png 或 https://example.com/images/logo.png。

路径示例 
<!-- 同一文件夹里的图片 -->
<img src="cat.jpg" alt="猫">

<!-- images 文件夹里的图片 -->
<img src="images/cat.jpg" alt="猫">

<!-- 上一级文件夹里的图片 -->
<img src="../cat.jpg" alt="猫">

<!-- 完整的网址 -->
<a href="https://example.com/about.html">关于我们</a>
常见误区：文件名区分大小写。写了 Cat.jpg，但文件夹里叫 cat.jpg，在某些系统上可能找不到图片。
为什么本地练习推荐相对路径：你的页面和图片在同一个项目文件夹里，浏览器可以根据当前页面的位置去找文件。本地练习里绝对路径很容易写错“网站根目录”在哪，上传到服务器后也可能需要重新调整；所以先从相对路径练起最稳。

怎么判断该用哪个属性？

最好的方法是看这个标签“需要什么信息”。链接需要地址，所以用 href；图片需要文件位置，所以用 src；多个元素想共用样式，就给他们同样的 class；一个元素想被精确定位，就给它唯一的 id。

  4. 保存并刷新，确认图片显示出来。

一个完整的表单

form.html

checkbox 可多选 <input type="checkbox">
radio 同一组只能选一个 <input type="radio">
file 选择文件 <input type="file">

第九章

表单校验：让浏览器帮你把关

上一章的表单能提交了，但用户填错了怎么办？这一章用浏览器自带的校验属性，在提交前就把错误拦下来，不用写一行 JavaScript。

本章目标

会用 required、pattern、minlength/maxlength、min/max 几个校验属性，并读懂浏览器的校验提示。

必填：required

给输入框加上 required 后，不填这一项就点提交，浏览器会弹出“请填写此字段”的提示，并阻止提交。它不需要任何 JavaScript。

index.html 
<form action="/signup" method="post">
  <label>用户名<input type="text" name="username" required></label>
  <button type="submit">注册</button>
</form>

格式：type 与 pattern

type="email" 会检查邮箱格式，type="url" 会检查网址格式。想自定义规则就用 pattern，它的值是一段正则表达式。比如手机号限定为 11 位数字：

index.html 
<input type="text" name="phone" pattern="[0-9]{11}">

正则 [0-9]{11} 的意思是“11 个 0 到 9 的数字”。HTML 的 pattern 会检查整个输入值，所以 [0-9]{11} 本身就表示“整段必须是 11 位数字”，不需要再加 ^ 和 $，加了也不会错。

长度与范围：minlength / maxlength / min / max

minlength / maxlength

限制文本的长度，例如密码 8～20 位：minlength="8" maxlength="20"。

min / max

限制数字输入框的范围，例如年龄 1～120：type="number" min="1" max="120"。

index.html 
<input type="password" name="password" minlength="8" maxlength="20" required>
<input type="number" name="age" min="1" max="120" required>

提示：在大多数浏览器里，maxlength 会阻止用户继续输入，而 minlength 只在提交时提示；两者配合 required 使用效果最好。

第十章

语义化：让结构表达意义

除了 <div>，HTML 还提供了很多“有名字”的容器。它们不仅方便你阅读代码，也帮助搜索引擎和无障碍工具理解页面。

本章目标

标准页面结构

<header>页面头部：网站名、导航等
<nav>导航菜单
<main> 页面的主体内容
<section>相关内容的区块

可访问性

搜索引擎

JSON-LD 是用 JSON 格式写给机器看的数据，告诉搜索引擎“这个页面是什么”。最常见的用法是文章和人物介绍。写好后可以在 Google 的 Rich Results 测试工具里检查。

index.html

{
  "@context": "https://schema.org",
  "@type": "Person",
  "name": "小明",
  "url": "https://example.com/"
}
</script>

第十二章

初见 CSS：让页面变好看

HTML 负责结构，CSS 负责外观。颜色、字体、间距、居中，全都是 CSS 的工作。

本章目标

三种写 CSS 的方式

1. 内联样式

直接写在标签的 style 属性里，适合快速调试。

<p style="color: red;">红字</p>

2. 页面内样式

<style>p { color: red; }</style>

3. 外部样式表

<link rel="stylesheet" href="style.css">

    <p>这段文字会变成深灰色。</p>

第十五章

响应式设计：一个页面适配所有屏幕

同一个页面，在手机、平板和电脑上都要好看。响应式设计的目标就是：不用做多个网页，也能自适应各种屏幕宽度。

本章目标

理解 viewport 的作用，会写 @media 媒体查询，并按“移动优先”的思路调整布局。

viewport：先告诉手机页面有多宽

没有 viewport 声明时，手机会按一个很宽的“虚拟桌面宽度”来缩小页面，字会小到看不清。加上下面这一行，页面宽度就等于手机屏幕宽度：

index.html 
<meta name="viewport" content="width=device-width, initial-scale=1.0">

媒体查询：@media

媒体查询让 CSS 在满足条件时换一套规则。下面这段的意思是：屏幕宽度不超过 600px 时，把三列布局改成单列。

style.css 
.cards {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
}

@media (max-width: 600px) {
  .cards {
    grid-template-columns: 1fr;
  }
}

max-width 是“窄到多少以下”，min-width 是“宽到多少以上”。日常记住一个方向就够了：先写手机版，再用 min-width 逐步增强。

移动优先：先手机，后桌面

先给手机写一份最简单的样式（单列、大按钮、少装饰），再用媒体查询在屏幕变宽时叠加更复杂的布局。这样做出来的页面通常更轻、更快。

style.css 
/* 手机版：默认就是单列 */
.cards {
  display: grid;
  grid-template-columns: 1fr;
}

/* 桌面版：宽度超过 768px 时再变成三列 */
@media (min-width: 768px) {
  .cards {
    grid-template-columns: 1fr 1fr 1fr;
  }
}

常见断点

≤ 600px

手机竖屏：单列布局、大按钮。

600～900px

平板与横屏手机：两列布局。

≥ 900px

桌面：三列甚至更多，导航完整展开。

断点没有标准答案，以内容不挤不空为准。

JSX 不是一门新语言，也不是模板字符串。它是 JavaScript 的一种语法扩展：让你在一个函数里，用接近 HTML 的写法直接描述界面。React 组件之所以看起来像“代码里长出了网页”，就是因为 JSX。

JSX 长什么样？

App.jsx 
function Greeting() {
  return (
    <div>
      <h1>你好，JSX</h1>

你可能会注意到，这看起来很像 HTML，但它不是 HTML。它是 JSX：一段被 React 理解的 JavaScript 代码。函数 Greeting 返回一段 JSX，React 会把它渲染成真正的网页元素。

JSX 和 HTML 哪里不一样？

场景 HTML 里 JSX 里 为什么
CSS 类名 class="card" className="card" class 在 JavaScript 里是保留词
点击事件 onclick="..." onClick={() => ...} JSX 属性名使用小驼峰（第一个单词小写、后面单词首字母大写，如 onClick），值可以传函数

花括号 {} 是 JSX 的灵魂

在 JSX 里，只要看到花括号，就代表“这里要执行 JavaScript”。你可以把变量、函数返回值、计算表达式放进花括号。

在 JSX 里使用表达式 
const name = "小林";
const age = 18;

function Profile() {
  return (
    <div>
      <h1>你好，{name}</h1>
      <p>今年 {age + 1} 岁</p>
      <p>名字长度：{name.length} 个字符</p>
    </div>
  );
}

{name} 会把变量的值写进页面；{age + 1} 会先计算再显示；{name.length} 会把字符串的长度显示出来。注意：花括号里写的是“表达式”，不是“完整的语句”。你不能把 if 直接写在花括号里。

列表怎么渲染？

用数组的 map 方法，把每个数据变成一段 JSX。列表项通常要加一个 key，帮助 React 识别每一项。

列表渲染 
const hobbies = ["读书", "拍照", "做饭"];

function HobbyList() {
  return (
    <ul>
      {hobbies.map((hobby) => (
        <li key={hobby}>{hobby}</li>
      ))}
    </ul>
  );
}

  );
}

从 JSX 到组件

当一段 JSX 被装进一个函数并返回，这个函数就是一个“组件”。组件可以接收外部传进来的参数，这些参数叫 props。props 让同一个组件在不同地方显示不同内容。

带 props 的组件 
function UserCard({ name, city }) {
  return (
    <div className="card">
      <h3>{name}</h3>
      <p>来自 {city}</p>
    </div>
  );
}

function App() {
  return (
    <div>
      <UserCard name="小林" city="上海" />
      <UserCard name="阿明" city="成都" />
    </div>
  );
}

export default App;

<UserCard name="小林" /> 里的 name 和 city 会被打包成一个 props 对象，传给组件函数。同一个组件因此可以复用在很多地方。

JSX 的六条规则

  1. 一个组件函数只能返回一个根元素，想返回多个内容就用一个 div 包住。
  2. 所有标签都必须闭合：<img />、<input />。
  3. 属性名使用小驼峰（第一个单词小写、后面单词首字母大写）：className、onClick、htmlFor。
  4. 花括号 {} 里写 JavaScript 表达式。
  5. style 是对象：style={{ fontSize: 18 }}。
  6. 注释写在花括号里：{/* 这是注释 */}。
这一章完全不涉及 TypeScript。你只需要知道：JSX 是“用 JavaScript 写界面”，等学会 TS 后，再把类型加进去，就成了 TSX。

  initial?: number;

State

组件自己的状态。状态变化时，React 会自动重新渲染界面。

Hooks

以 use 开头的函数，例如 useState、useEffect，用来管理状态和副作用。

标签记不住怎么办？
完全正常。熟练开发者也会经常查文档。重点不是背住所有标签，而是理解“标签 = 给内容贴说明”这个逻辑。
只学 HTML 能做出完整网站吗？
能做出“结构完整但没有样式、不能保存数据”的页面。真正完整的网站还需要 CSS 负责外观、JavaScript 负责交互，后端负责数据。
为什么我的中文变成乱码？
绝大多数是因为缺少 <meta charset="UTF-8">，或者编辑器保存文件时用了其他编码。把文件重新保存为 UTF-8，并确认 head 里有 charset 即可。
JSX 和 TSX 有什么区别？
JSX 是在 JavaScript 里写界面的语法；TSX 是在 JSX 的基础上加入 TypeScript 类型。学习顺序建议是先写纯 JSX，理解组件、props、列表和条件渲染，再学 TypeScript，最后进入 TSX。
遇到卡点时，先按这个顺序自查
  • 文件保存了吗？文件名和扩展名对吗？
  • 浏览器刷新了吗？还是打开的是旧页面？
  • 标签有没有闭合？嵌套顺序对不对？
  • 路径里的文件夹、文件名、大小写对吗？
  • 控制台和网络面板里有没有报错？
