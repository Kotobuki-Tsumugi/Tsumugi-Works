第一章

学习前的准备：安装 Go 与环境

学 Go 之前只需要做一件事：把 Go 装到你的电脑上。这一章不写业务代码，只完成“安装 → 验证 → 准备编辑器”三件事。

本章目标

安装 Go 工具链，能在终端里看到 go version 的输出，并建好一个 Go 模块。

下载并安装 Go

Windows

到 go.dev/dl 下载 .msi 安装包，双击安装，一路下一步即可。装完重开终端。

macOS

可以下载 .pkg 安装，也可以用 Homebrew：brew install go。

Linux

下载 .tar.gz 解压到 /usr/local，并把 /usr/local/go/bin 加入 PATH。

验证安装：go version

装好后，打开终端（Windows 上是 PowerShell），输入下面的命令。能看到版本号，就说明安装成功。

终端 
go version
运行结果
go version go1.23.4 windows/amd64

版本号里的 go1.23.4 是 Go 的版本，windows/amd64 是当前系统。数字不同没关系，只要不是报“不是内部或外部命令”就行。

初始化一个模块：go mod init

现代 Go 项目都以“模块（module）”为单位。新建一个文件夹，在里面执行 go mod init，Go 会生成一个 go.mod 文件，记录模块名和依赖。

终端 
mkdir my-first-go
cd my-first-go
go mod init my-first-go
运行结果
go: creating new go.mod: module my-first-go
go: to add module requirements and sums:
        go mod tidy

模块名可以任意起，规范是“域名/路径”的形式，比如 github.com/你的名字/项目名。本地练习随便起就行。

准备编辑器：VS Code + Go 插件

推荐 VS Code（免费），装好之后再安装官方的 Go 扩展。第一次写 Go 文件时，编辑器会提示安装代码补全等工具，全部同意即可。装上后你会获得：自动补全、保存自动格式化（gofmt）、悬停看文档。

常见误区：不需要装任何“Go 编译器”以外的软件。Go 的安装包里已经包含了编译器、运行器和格式化工具，一条命令全搞定。

第二章

Go 是什么？为什么学它

如果你学过 HTML，你已经知道“标记语言”是什么。Go 是一门真正的编程语言：它能做计算、做判断、做循环，还能同时处理成千上万个任务。

本章目标

理解 Go 的三个核心特点：编译型、静态类型、并发优先，并知道它适合做什么。

HTML 和 Go 有什么区别？

HTML Go
类型 标记语言，描述结构 编程语言，描述逻辑
能不能计算 不能 能

Go 的三大特点

编译型

go build 会把代码编译成一个单独的可执行文件，复制到任何电脑上都能直接运行，不需要先装环境。

静态类型

变量的类型在写代码时就要明确，编译期就能发现大部分错误，而不是运行到一半才崩。

并发优先

用 go 关键字就能开一个“协程”（goroutine），语言层面原生支持并发，这是 Go 最出名的能力。

谁在用 Go？

Docker、Kubernetes 这两个改变云计算的工具都用 Go 编写。国内很多公司（字节跳动、腾讯、七牛等）用 Go 构建高并发的后端服务。学完基础后，你完全有能力阅读 Docker 这样的大型开源项目源码。

你的第一个 Go 程序

现在动手写第一个程序。它只有几行，但包含了 Go 程序的全部骨架：包、导入、主函数、输出。

新建 hello.go

main.go

拆解：四行代码分别是什么意思？

package main

声明这个文件属于 main 包。想生成可执行文件，程序必须从 package main 开始。

func main()

定义主函数，程序从这里开始执行。花括号 {} 包住函数体。

fmt.Println(...)

调用函数并传参。Go 的调用语法是 包名.函数名(参数)。

第四章

变量与常量

程序就是“把数据存进变量，再对变量做运算”。这一章学会 Go 里声明变量的两种方式和常量的写法。

本章目标

会用 var 和 := 声明变量，会用 const 声明常量，并理解“零值”的概念。

声明变量：var

var 是 Go 里声明变量的关键字，格式是 var 名字 类型 = 值。类型和值可以只写其中一个：

main.go 
package main

import "fmt"

func main() {
    var name string = "小明" // 完整写法：类型和值都写
    var age int              // 只写类型，稍后再赋值
    age = 18

    var height = 172.5 // 省略类型，Go 自动推断

    fmt.Println(name, age, height)
}
运行结果
小明 18 172.5

短声明：:=

在函数内部，可以用 := 一步完成“声明 + 赋值”，类型由 Go 自动推断。这是 Go 代码里最常见的写法：

main.go 
package main

import "fmt"

func main() {
    city := "上海"   // 声明字符串变量
    count := 3       // 声明整数变量
    price := 9.9     // 声明浮点数变量
    open := true     // 声明布尔变量

    fmt.Println(city, count, price, open)
}
运行结果
上海 3 9.9 true
注意：:= 只能在函数内部使用。在函数外面（包级别）声明变量只能用 var。

常量：const

值永远不会变的量用 const 声明。比如圆周率、网站最大重试次数：

main.go 
package main

import "fmt"

const Pi = 3.14159
const MaxRetry = 3

func main() {
    fmt.Println("圆周率约等于", Pi)
    fmt.Println("最多重试", MaxRetry, "次")
}
运行结果
圆周率约等于 3.14159
最多重试 3 次

零值：声明但不赋值

Go 里声明了变量却没赋值，它也有一个默认值，叫“零值”。数字是 0，字符串是空串 ""，布尔是 false。所以不用担心“用了未初始化的变量”。

main.go 
package main

import "fmt"

func main() {
    var n int
    var s string
    var ok bool

    fmt.Printf("n=%d s=%q ok=%v\n", n, s, ok)
}
运行结果
n=0 s="" ok=false

%q 会输出带引号的字符串，方便看出空串。

命名习惯

驼峰命名

多词变量用驼峰：userName、maxRetry，不要用下划线 user_name。

见名知意

用 totalPrice 而不是 tp；循环计数习惯用 i、j。

声明了就要用

Go 不允许声明变量却不用，编译器会直接报错。这不是找茬，是帮你保持代码干净。

  2. 用 var 声明一个变量，先不赋值，打印它的零值。

第五章

基本类型与格式化输出

上一章你已经见过了 string、int、float64、bool。这一章把它们讲透，并学会用 fmt.Printf 精确控制输出格式。

本章目标

认识四种基本类型，会用 fmt.Printf 的常用动词，会做安全的类型转换。

四种基本类型

int 整数

不含小数：42、-7。还有更精细的 int8/int16/int32/int64，日常用 int 即可。

float64 浮点数

含小数：3.14。float32 精度较低，日常用 float64。

string 字符串

一串文字，用双引号包起来："你好"。反引号可以写多行文本。

bool 布尔

只有两个值：true 和 false，用于判断。

fmt.Printf：按格式输出

fmt.Println 适合快速打印；fmt.Printf 用 % 开头的“动词”控制格式，把变量填进模板里：

main.go 
package main

import "fmt"

func main() {
    name := "小明"
    age := 18
    score := 92.5

    fmt.Printf("姓名：%s\n", name)   // %s 字符串
    fmt.Printf("年龄：%d 岁\n", age) // %d 整数
    fmt.Printf("分数：%.1f\n", score) // %.1f 保留一位小数
    fmt.Printf("类型：%T\n", score)   // %T 输出类型
}
运行结果
姓名：小明
年龄：18 岁
分数：92.5
类型：float64

常用动词速查

动词 作用 示例
%s字符串fmt.Printf("%s", "Hi")
%d整数fmt.Printf("%d", 42)
%f浮点数fmt.Printf("%.2f", 3.14159)
%t布尔值fmt.Printf("%t", true)
%v通用值（万能）fmt.Printf("%v", 变量)
%T类型fmt.Printf("%T", x)
\n换行写在格式串里

记不住没关系，最常用的就是 %v（调试万能）和 \n（换行）。

类型转换

Go 不会偷偷把类型转来转去，需要手动写转换：类型(值)。

main.go 
package main

import "fmt"

func main() {
    n := int(3.7)      // 浮点数转整数，直接截断小数
    f := float64(5)    // 整数转浮点数
    s := string(rune(65)) // 数字转字符：65 对应 'A'

    fmt.Println(n, f, s)
}
运行结果
3 5 A
易错点：string(65) 得到的是字符 "A"，不是字符串 "65"。数字转字符串要用 strconv.Itoa，下一章会讲。

第六章

条件与循环

程序会“做判断”和“重复做事”。Go 的语法很克制：判断只有 if 和 switch，循环只有 for——没有 while、没有 do-while，一个 for 全搞定。

本章目标

会用 if/else、switch 做分支，会用 for 的三种形式做循环，会用 break 和 continue 控制流程。

if / else if / else

Go 的 if 不需要括号，条件后面直接跟花括号。else 必须和上一个花括号在同一行：

main.go 
package main

import "fmt"

func main() {
    score := 85

    if score >= 90 {
        fmt.Println("优秀")
    } else if score >= 60 {
        fmt.Println("及格")
    } else {
        fmt.Println("不及格")
    }
}
运行结果
及格

Go 的 if 还能在条件前先声明一个变量，这个变量只在 if 块里有效：

main.go 
package main

import "fmt"

func main() {
    price := 120
    if discount := price - 20; discount >= 100 {
        fmt.Println("打折后仍超过 100：", discount)
    }
}
运行结果
打折后仍超过 100： 100

switch：多个分支更清晰

当判断很多时，switch 比一长串 else if 更整洁。Go 的 switch 不需要 break，匹配到就自动退出：

main.go 
package main

import "fmt"

func main() {
    day := "周六"

    switch day {
    case "周六", "周日":
        fmt.Println("休息日")
    case "周五":
        fmt.Println("快到周末了")
    default:
        fmt.Println("工作日")
    }
}
运行结果
休息日

for：三种写法

标准写法

初始化；条件；步进：for i := 0; i < 5; i++ { ... }

当作 while

只写条件：for n > 0 { ... }，等价于其他语言的 while。

无限循环

什么都不写：for { ... }，配合 break 退出。

main.go 
package main

import "fmt"

func main() {
    // 标准写法：1 到 5
    for i := 1; i <= 5; i++ {
        fmt.Println("第", i, "次")
    }

    // while 式：倒数
    n := 3
    for n > 0 {
        fmt.Println("倒计时", n)
        n--
    }
}
运行结果
第 1 次
第 2 次
第 3 次
第 4 次
第 5 次
倒计时 3
倒计时 2
倒计时 1

break 与 continue

break 立刻跳出循环，continue 跳过本次继续下一次：

main.go 
package main

import "fmt"

func main() {
    for i := 1; i <= 10; i++ {
        if i%2 == 0 {
            continue // 偶数跳过
        }
        if i > 7 {
            break // 超过 7 停止
        }
        fmt.Println(i)
    }
}
运行结果
1
3
5
7

i%2 == 0 表示 i 能被 2 整除（取余为 0），所以打印的都是奇数。

第七章

函数

函数把一段逻辑包起来，起个名字，以后随时调用。Go 的函数有个标志性特点：可以返回多个值——最经典的就是“返回值 + 错误”。

本章目标

会定义和调用函数，会用多返回值、命名返回值、可变参数，并理解函数是一等公民。

定义和调用函数

格式是 func 名字(参数) 返回类型 { ... }。参数写“名字 类型”，多个参数用逗号隔开：

main.go 
package main

import "fmt"

func greet(name string) string {
    return "你好，" + name + "！"
}

func main() {
    message := greet("小明")
    fmt.Println(message)
}
运行结果
你好，小明！

多返回值

函数可以返回多个值，调用时用多个变量接收。Go 里最常见的用法是同时返回“结果”和“错误”：

main.go 
package main

import "fmt"

func divide(a, b float64) (float64, string) {
    if b == 0 {
        return 0, "不能除以零"
    }
    return a / b, ""
}

func main() {
    result, problem := divide(10, 4)
    fmt.Println(result, problem)

    result, problem = divide(10, 0)
    fmt.Println(result, problem)
}
运行结果
2.5 
0 不能除以零

同类型的连续参数可以合并写：a, b float64 等价于 a float64, b float64。

命名返回值

返回类型可以起名字，函数体内直接给它们赋值，末尾写一个光秃秃的 return 即可：

main.go 
package main

import "fmt"

func area(w, h float64) (result float64) {
    result = w * h
    return // 等价于 return result
}

func main() {
    fmt.Println(area(3, 4))
}
运行结果
12

可变参数：...

参数前加 ...，函数就能接收任意多个同类型参数，函数内把它当切片用：

main.go 
package main

import "fmt"

func sum(nums ...int) int {
    total := 0
    for _, n := range nums {
        total += n
    }
    return total
}

func main() {
    fmt.Println(sum(1, 2, 3))
    fmt.Println(sum(10, 20, 30, 40))
}
运行结果
6
100

递归：函数调用自己

计算阶乘：5! = 5×4×3×2×1。递归函数一定要有终止条件，否则会无限循环：

main.go 
package main

import "fmt"

func factorial(n int) int {
    if n <= 1 {
        return 1
    }
    return n * factorial(n-1)
}

func main() {
    fmt.Println(factorial(5))
}
运行结果

第八章

错误处理：错误也是一种值

程序总会遇到意外：文件不存在、网络断开、数字不合法。Go 的处理方式很直接——把错误当作普通返回值传递，由调用者决定怎么处理。

本章目标

理解 error 是接口，会用 errors.New、fmt.Errorf 构造错误，会用 defer 收尾，并知道 panic 是什么。

错误是返回值

标准库函数几乎都返回 (结果, error)。判断 err != nil 是 Go 里最常见的代码：

main.go 
package main

import (
    "errors"
    "fmt"
)

func checkAge(age int) (string, error) {
    if age < 0 {
        return "", errors.New("年龄不能是负数")
    }
    return fmt.Sprintf("年龄 %d", age), nil
}

func main() {
    message, err := checkAge(-1)
    if err != nil {
        fmt.Println("出错了：", err)
        return
    }
    fmt.Println(message)
}
运行结果
出错了： 年龄不能是负数

没有错误时返回 nil（空值）。err != nil 的意思是“有错误”。

带更多信息：fmt.Errorf

fmt.Errorf 可以像格式化输出一样拼出错误信息，还能用 %w 把底层错误“包”起来，保留错误链条：

main.go 
package main

import (
    "errors"
    "fmt"
)

func loadUser(name string) error {
    if name == "" {
        return errors.New("用户名不能为空")
    }
    return fmt.Errorf("加载用户 %s 失败：%w", name, errors.New("用户不存在"))
}

func main() {
    err := loadUser("")
    fmt.Println(err)
}
运行结果
用户名不能为空

defer：离开前一定要做的事

defer 会把一条语句推迟到函数结束前执行，最常用于“关闭文件、解锁资源”。即使中途 return，defer 也会执行：

main.go 
package main

import "fmt"

func main() {
    defer fmt.Println("1. 最后执行")
    fmt.Println("2. 先执行")
    fmt.Println("3. 中间执行")
}
运行结果
2. 先执行
3. 中间执行
1. 最后执行

多个 defer 会按“后声明先执行”的顺序运行（像叠盘子）。第十九章读文件时会再次见到它的实际用法。

第九章

数组与切片

想存一串数据怎么办？Go 有数组（定长）和切片（变长）。实际开发里 99% 用的是切片，因为它的长度可以动态变化。

数组：长度固定

main.go 
package main

import "fmt"

func main() {
    var scores [3]int
    scores[0] = 90
    scores[1] = 85
    scores[2] = 78

    fmt.Println("长度：", len(scores))
}

切片：长度可变

切片是数组的“动态视图”，用 []类型 声明。字面量写法和数组很像，只是不写长度：

main.go 
package main

import "fmt"

func main() {
    fruits := []string{"苹果", "香蕉", "橙子"}

    fmt.Println(fruits)
    fmt.Println("数量：", len(fruits))
}
运行结果
[苹果 香蕉 橙子 葡萄]
数量： 4

切片切割：s[1:3]

用 [开始:结束] 取子切片，注意“含头不含尾”：

main.go 
package main

import "fmt"

func main() {
    nums := []int{10, 20, 30, 40, 50}

    fmt.Println(nums[1:3]) // 下标 1 到 2
    fmt.Println(nums[:2])  // 开头到下标 1
    fmt.Println(nums[3:])  // 下标 3 到末尾
}
运行结果
[20 30]
[10 20]
[40 50]

make 与 copy

make([]int, 长度, 容量) 预先分配空间，适合已知大小的场景；copy 复制切片内容，避免共享底层数组：

main.go 
package main

import "fmt"

func main() {
    a := make([]int, 3) // 长度为 3，默认值 0
    fmt.Println(a)

    b := []int{1, 2, 3}
    c := make([]int, len(b))
    copy(c, b) // 把 b 的内容复制到 c
    c[0] = 99

    fmt.Println(b) // b 不受影响
    fmt.Println(c)
}
运行结果
[0 0 0]
[1 2 3]
[99 2 3]

package main

import "fmt"

func main() {

    }

    sum := 0
    for _, n := range []int{2, 4, 6} {
        sum += n
    }
    fmt.Println("总和：", sum)
}
运行结果

1 小红
2 小刚

第十章

map：键值对字典

切片用下标取数据，map 用“键”取数据。它就像一本字典：查“姓名”得到“小明”。map 是 Go 里最常用的数据结构之一。

本章目标

会创建、读取、修改、删除 map，会判断键是否存在，并了解 map 的遍历顺序与并发注意事项。

创建 map

类型写法是 map[键类型]值类型，例如 map[string]int。用字面量或 make 创建：

main.go 
package main

import "fmt"

func main() {
    scores := map[string]int{
        "小明": 90,
        "小红": 85,
    }

    var another map[string]int // 只声明，还不能用
    _ = another

    grades := make(map[string]int) // make 创建，可用
    grades["小刚"] = 78

    fmt.Println(scores)
    fmt.Println(grades)
}
运行结果
map[小明:90 小红:85]
map[小刚:78]
注意：只声明不初始化的 map 是 nil，往里面写数据会崩溃。一律用字面量或 make 初始化。

读取与判断键是否存在

读取不存在的键会得到“零值”，分不清是“值为 0”还是“键不存在”。用双赋值可以明确判断：

main.go 
package main

import "fmt"

func main() {
    scores := map[string]int{"小明": 90}

    v1 := scores["小明"]     // 只有一个返回值
    v2, ok := scores["路人"] // 双赋值：v2 是值，ok 是是否存在

    fmt.Println(v1)
    fmt.Println(v2, ok)

    if score, exists := scores["小明"]; exists {
        fmt.Println("小明在，分数", score)
    }
}
运行结果
90
0 false
小明在，分数 90

修改与删除

直接赋值就修改；delete(m, key) 删除键：

main.go 
package main

import "fmt"

func main() {
    stock := map[string]int{"苹果": 5, "香蕉": 3}

    stock["苹果"] = 10 // 修改
    stock["橙子"] = 8  // 新增
    delete(stock, "香蕉") // 删除

    fmt.Println(stock)
    fmt.Println("数量：", len(stock))
}
运行结果
map[橙子:8 苹果:10]
数量： 2

遍历与统计

用 range 遍历 map。注意：map 的遍历顺序是随机的，不要依赖顺序：

main.go 
package main

import "fmt"

func main() {
    words := []string{"go", "go", "rust", "go"}
    counts := map[string]int{}

    for _, w := range words {
        counts[w]++
    }

    for word, n := range counts {
        fmt.Println(word, n)
    }
}
运行结果（顺序可能不同）
go 3
rust 1

这个“统计每个词出现次数”的写法是面试和项目里的经典场景：counts[w]++ 对不存在的键也能安全加 1。

用 map 模拟集合

Go 没有内置的 set（集合），用 map[类型]bool 或 map[类型]struct{} 来去重：

main.go 
package main

import "fmt"

func main() {
    ids := []string{"a1", "b2", "a1", "c3"}
    seen := map[string]bool{}
    unique := []string{}

    for _, id := range ids {
        if !seen[id] {
            seen[id] = true
            unique = append(unique, id)
        }
    }

    fmt.Println(unique)
}
运行结果
[a1 b2 c3]

第十三章

方法与指针

结构体有了，能不能像“对象”一样有自己的行为？Go 用“方法（method）”实现：给类型绑定函数。指针则让函数能真正修改传入的数据。

本章目标

会给结构体定义方法，理解值接收者与指针接收者的区别，会用 & 和 * 操作指针。

给结构体定义方法

方法就是在函数名前加一个“接收者（receiver）”：func (接收者 类型) 方法名()：

main.go 
package main

import "fmt"

type Circle struct {
    Radius float64
}

func (c Circle) Area() float64 {
    return 3.14 * c.Radius * c.Radius
}

func main() {
    c := Circle{Radius: 10}
    fmt.Println("面积：", c.Area())
}
运行结果
面积： 314

指针接收者：让方法能修改数据

接收者写成 *Circle（指针），方法里就能直接改字段；写成 Circle（值），改的只是一份拷贝：

main.go 
package main

import "fmt"

type Counter struct {
    N int
}

func (c Counter) ValueAdd() { // 值接收者：改的是拷贝
    c.N++
}

func (c *Counter) PointerAdd() { // 指针接收者：改的是原对象
    c.N++
}

func main() {
    c := Counter{N: 1}
    c.ValueAdd()
    fmt.Println("值接收者调用后：", c.N)

    c.PointerAdd()
    fmt.Println("指针接收者调用后：", c.N)
}
运行结果
值接收者调用后： 1
指针接收者调用后： 2

什么时候用指针接收者？两个原则：方法要修改数据时用指针；结构体很大时用指针避免复制开销。

& 和 *：取地址与解引用

&x 得到 x 的地址（指针），*p 通过指针取回 x 的值（解引用）：

main.go 
package main

import "fmt"

func main() {
    n := 10
    p := &n // p 是指向 n 的指针

    fmt.Println("n 的值：", n)
    fmt.Println("p 指向的地址：", p)
    fmt.Println("通过 p 读值：", *p)

    *p = 20 // 通过指针修改 n
    fmt.Println("修改后 n：", n)
}
运行结果
n 的值： 10
p 指向的地址： 0xc0000120a8
通过 p 读值： 10
修改后 n： 20

地址的数字每次运行都可能不同，这很正常，你只需要知道 & 取地址、* 取值。

把指针传给函数

函数参数写 *类型，调用时传 &变量，就能在函数里修改外部变量：

main.go 
package main

import "fmt"

func double(n *int) {
    *n = *n * 2
}

func main() {
    score := 50
    double(&score)
    fmt.Println("加倍后：", score)
}
运行结果
加倍后： 100

第十四章

接口：只关心“能做什么”

接口（interface）描述一组“能力”。只要一个类型具备这些方法，就算实现了这个接口——不需要写 implements，Go 是隐式实现。

本章目标

理解接口是方法集合，会定义接口并用它写通用代码，会用空接口和类型断言。

定义接口

接口只写方法签名，不写实现。任何拥有这些方法的类型都自动满足接口：

main.go 
package main

import "fmt"

type Speaker interface {
    Speak() string
}

type Dog struct{}

func (d Dog) Speak() string {
    return "汪汪"
}

type Cat struct{}

func (c Cat) Speak() string {
    return "喵喵"
}

func main() {
    animals := []Speaker{Dog{}, Cat{}}
    for _, a := range animals {
        fmt.Println(a.Speak())
    }
}
运行结果
汪汪
喵喵

Dog 和 Cat 都没有声明“我实现了 Speaker”，但只要方法对得上，Go 就认为实现了。

用接口写通用函数

接口最大的价值：函数只依赖接口，不依赖具体类型，任何实现都能传进来：

main.go 
package main

import "fmt"

type Area interface {
    Area() float64
}

type Square struct {
    Side float64
}

func (s Square) Area() float64 {
    return s.Side * s.Side
}

type Circle struct {
    Radius float64
}

func (c Circle) Area() float64 {
    return 3.14 * c.Radius * c.Radius
}

func printArea(a Area) {
    fmt.Println("面积：", a.Area())
}

func main() {
    printArea(Square{Side: 4})
    printArea(Circle{Radius: 10})
}
运行结果
面积： 16
面积： 314

第十五章

泛型：一套代码，多种类型

写一个“求最大值”的函数，只支持 int 太浪费，支持 float64 又得复制一份。Go 1.18 引入的泛型让你写一次，任意类型都能用。

本章目标

会写带类型参数（[T]）的泛型函数，会使用约束（constraint），能读懂标准库里的泛型代码。

类型参数：[T]

函数名后加 [T any]，参数里就能用 T 代替具体类型。any 表示“任意类型”，但任意类型能做算术吗？不行——所以下面的例子用比较运算符：

main.go 
package main

import "fmt"

func maxValue[T int | float64](a, b T) T {
    if a > b {
        return a
    }
    return b
}

func main() {
    fmt.Println(maxValue(3, 7))
    fmt.Println(maxValue(1.5, 1.2))
}
运行结果
7
1.5

[T int | float64] 里的 | 表示“或”：T 可以是 int 或 float64。

约束（constraint）

约束写多了会重复，可以抽出来命名，还能组合：

main.go 
package main

import "fmt"

type Number interface {
    int | int64 | float64
}

func sumAll[T Number](nums []T) T {
    var total T
    for _, n := range nums {
        total += n
    }
    return total
}

func main() {
    fmt.Println(sumAll([]int{1, 2, 3}))
    fmt.Println(sumAll([]float64{1.5, 2.5}))
}
运行结果
6
4

var total T 的零值是 0，所以可以安全地累加。

泛型切片操作

标准库 Go 1.21+ 提供 slices 包，也是泛型实现的。自己写一个“查找元素”练手：

main.go 
package main

import "fmt"

func contains[T comparable](items []T, target T) bool {
    for _, item := range items {
        if item == target {
            return true
        }
    }
    return false
}

func main() {
    fmt.Println(contains([]string{"go", "rust"}, "go"))
    fmt.Println(contains([]int{1, 2, 3}, 9))
}
运行结果
true
false

comparable 是内置约束，表示“可以比较相等”，支持 ==。

什么时候别用泛型

类型只有一种

只有一个类型会用到时，泛型只是增加阅读负担。

逻辑完全不同

各类型处理逻辑差异很大时，硬套泛型反而难懂。

接口更合适

需要一组方法而不是任意类型时，用接口更清晰。

第十六章

并发：goroutine

Go 的并发模型非常轻量：在函数调用前加一个 go，它就在一个新的 goroutine 里运行了。你可以同时开成千上万个，而不用担心内存爆炸。

本章目标

会用 go 关键字启动 goroutine，会用 sync.WaitGroup 等待它们完成，并理解数据竞争的危险。

启动 goroutine

go 函数() 会让函数在后台并发执行，主函数不会等它：

main.go 
package main

import (
    "fmt"
    "time"
)

func say(word string) {
    for i := 0; i < 3; i++ {
        fmt.Println(word)
        time.Sleep(10 * time.Millisecond)
    }
}

func main() {
    go say("后台任务") // 并发运行
    say("主任务")
}
运行结果（顺序每次可能不同）
主任务
后台任务
主任务
后台任务
主任务
后台任务

两个函数交替输出，说明它们在同时执行。注意：如果 main 提前结束，后台 goroutine 也会被带走。

WaitGroup：等待全部完成

sync.WaitGroup 像计数器：Add(1) 加一，Done() 减一，Wait() 阻塞到归零。这是“等所有 goroutine 干完”的标准姿势：

main.go 
package main

import (
    "fmt"
    "sync"
)

func work(id int, wg *sync.WaitGroup) {
    defer wg.Done() // 结束时计数减一
    fmt.Println("任务", id, "完成")
}

func main() {
    var wg sync.WaitGroup

    for i := 1; i <= 5; i++ {
        wg.Add(1) // 启动前计数加一
        go work(i, &wg)
    }

    wg.Wait() // 等所有任务完成
    fmt.Println("全部完成")
}
运行结果（顺序可能不同）
任务 5 完成
任务 1 完成
任务 2 完成
任务 3 完成
任务 4 完成
全部完成

匿名函数启动 goroutine

不需要单独定义函数时，可以直接用匿名函数，配合闭包捕获外部变量：

main.go 
package main

import (
    "fmt"
    "sync"
)

func main() {

            fmt.Println("第", n, "个任务")

    wg.Wait()
}

第 1 个任务
第 2 个任务

第十七章

并发：channel 通信

Go 的并发名言：“不要通过共享内存来通信，而要通过通信来共享内存。”channel（通道）就是 goroutine 之间传递数据的管道。

本章目标

会创建和收发 channel，会用带缓冲的 channel、range 遍历和 select 多路选择。

创建与收发

用 make(chan 类型) 创建，ch <- 值 发送，值 := <-ch 接收。没有缓冲的 channel 会阻塞等待对方：

main.go 
package main

import "fmt"

func main() {
    ch := make(chan string)

    go func() {
        ch <- "你好，来自 goroutine" // 发送
    }()

    message := <-ch // 接收
    fmt.Println(message)
}
运行结果
你好，来自 goroutine

带缓冲的 channel

make(chan int, 3) 允许先存 3 条再取，发送方不会立刻阻塞：

main.go 
package main

import "fmt"

func main() {
    ch := make(chan int, 3)

    ch <- 1
    ch <- 2
    ch <- 3

    fmt.Println(<-ch)
    fmt.Println(<-ch)
    fmt.Println(<-ch)
}
运行结果
1
2
3

生产者与消费者

经典模式：一个 goroutine 生产数据，另一个消费。用 close 关闭 channel，接收方用 range 自动取完所有数据：

main.go 
package main

import "fmt"

func producer(ch chan<- int) {
    for i := 1; i <= 5; i++ {
        ch <- i
    }
    close(ch) // 发完关闭
}

func main() {
    ch := make(chan int)
    go producer(ch)

    for n := range ch { // 自动取到 channel 关闭
        fmt.Println("收到：", n)
    }
}
运行结果
收到： 1
收到： 2
收到： 3
收到： 4
收到： 5

select：同时等多个 channel

select 会阻塞，直到某个 case 可以执行；多个都行时随机选一个。常用来做“超时”和“多路消息”：

main.go 
package main

import (
    "fmt"
    "time"
)

func main() {
    ch1 := make(chan string)
    ch2 := make(chan string)

    go func() { time.Sleep(50 * time.Millisecond); ch1 <- "快消息" }()
    go func() { time.Sleep(200 * time.Millisecond); ch2 <- "慢消息" }()

    for i := 0; i < 2; i++ {
        select {
        case msg := <-ch1:
            fmt.Println(msg)
        case msg := <-ch2:
            fmt.Println(msg)
        }
    }
}
运行结果
快消息
慢消息

用 channel 修复计数器

回顾上一章的数据竞争：让所有 goroutine 通过 channel 把结果传回，主 goroutine 统一累加，就没有竞争了：

main.go 
package main

import "fmt"

func main() {
    ch := make(chan int, 1000)

    for i := 0; i < 1000; i++ {
        go func() {
            ch <- 1 // 每个 goroutine 只发数据
        }()
    }

    total := 0
    for i := 0; i < 1000; i++ {
        total += <-ch // 主 goroutine 统一累加
    }
    fmt.Println("计数器：", total)
}
运行结果
计数器： 1000

把结构体切片序列化后写进文件，再读回来：这是第二十五章待办清单项目的核心思路：

main.go 
package main

import (
    "encoding/json"
    "fmt"
    "os"
)

type Task struct {
    Title  string `json:"title"`
    Done   bool   `json:"done"`
}

func main() {
    tasks := []Task{
        {Title: "学习 Go", Done: true},
        {Title: "写项目", Done: false},
    }

    data, _ := json.Marshal(tasks)
    os.WriteFile("tasks.json", data, 0644)

    raw, err := os.ReadFile("tasks.json")
    if err != nil {
        fmt.Println("读取失败：", err)
        return
    }
    var loaded []Task
    json.Unmarshal(raw, &loaded)
    fmt.Println(loaded)
}
运行结果
[{学习 Go true} {写项目 false}]

HTTP 与 Web 服务

Go 最出名的领域就是后端服务。标准库 net/http 足够写出一个能跑的 Web 服务器，不需要任何第三方框架。

本章目标

会用 net/http 启动服务器、注册路由、读取参数，并返回 JSON 响应。

第一个服务器

main.go 
package main

import (
    "fmt"
    "net/http"
)

func hello(w http.ResponseWriter, r *http.Request) {
    fmt.Fprintln(w, "你好，Go Web！")
}

func main() {
    http.HandleFunc("/", hello)
    fmt.Println("服务器启动：http://localhost:8080")
    http.ListenAndServe(":8080", nil)
}
运行结果（另开终端访问）
服务器启动：http://localhost:8080

运行后在浏览器打开 http://localhost:8080，就能看到响应文字。w 是写给客户端的响应，r 是客户端发来的请求。

用 r.URL.Query() 读取 URL 里的 ?key=value 参数：

package main

import (
    "fmt"
    "net/http"
)

func greet(w http.ResponseWriter, r *http.Request) {
    name := r.URL.Query().Get("name")
    if name == "" {
        name = "陌生人"
    }
    fmt.Fprintf(w, "你好，%s！", name)
}

func main() {
    http.HandleFunc("/greet", greet)
    http.ListenAndServe(":8080", nil)
}

返回 JSON

后端接口最常返回 JSON。设置 Content-Type 头，再用 json.NewEncoder 输出：

main.go 
package main

import (
    "encoding/json"
    "net/http"
)

type Message struct {
    Text string `json:"text"`
    Code int    `json:"code"`
}

func api(w http.ResponseWriter, r *http.Request) {
    w.Header().Set("Content-Type", "application/json")
    json.NewEncoder(w).Encode(Message{
        Text: "成功",
        Code: 200,
    })
}

func main() {
    http.HandleFunc("/api", api)
    http.ListenAndServe(":8080", nil)
}
访问 /api 得到的响应
{"text":"成功","code":200}

编写测试

测试不是写完代码后的加分项，而是保证程序正确的日常工具。Go 的测试极简：文件名以 _test.go 结尾，函数名以 Test 开头，跑一个 go test 就行。

被测函数

package main

    return a + b
}

表驱动测试

同一函数测多组数据时，用“表格”写测试是 Go 社区的惯例：

calc_test.go 
package main

import "testing"

func TestAddTable(t *testing.T) {
    cases := []struct {
        name string
        a, b int
        want int
    }{
        {"正数相加", 1, 2, 3},
        {"负数相加", -1, -2, -3},
        {"零参与", 0, 5, 5},
    }

    for _, c := range cases {
        t.Run(c.name, func(t *testing.T) {
            if got := add(c.a, c.b); got != c.want {
                t.Errorf("add(%d,%d) = %d，期望 %d", c.a, c.b, got, c.want)
            }
        })
    }
}

t.Run 让每个用例独立成子测试，失败时能精确定位是哪一组。

调试与工具

写代码一定会遇到报错。Go 的报错信息非常友好：它会告诉你文件名、行号、出错原因。学会读报错，调试就成功了一半。

终端

go.sum：版本指纹

锁版本

go.mod 记录了确切版本，别人 clone 后 go build 得到一致结果。

提交两个文件

go.mod 和 go.sum 都要提交到 git，缺一不可。

第一步：定义数据与存储

新建 todo.go，定义任务结构体和读写函数：

todo.go 
package main

import (
    "encoding/json"
    "os"
)

type Task struct {
    ID    int    `json:"id"`
    Title string `json:"title"`
    Done  bool   `json:"done"`
}

const taskFile = "tasks.json"

func loadTasks() ([]Task, error) {
    data, err := os.ReadFile(taskFile)
    if err != nil {
        if os.IsNotExist(err) {
            return []Task{}, nil // 文件不存在就当空列表
        }
        return nil, err
    }
    var tasks []Task
    if err := json.Unmarshal(data, &tasks); err != nil {
        return nil, err
    }
    return tasks, nil
}

func saveTasks(tasks []Task) error {
    data, err := json.MarshalIndent(tasks, "", "  ")
    if err != nil {
        return err
    }
    return os.WriteFile(taskFile, data, 0644)
}

os.IsNotExist 判断“文件不存在”这个特定错误；json.MarshalIndent 生成带缩进、人类可读的 JSON。

第三步：实现三个命令

commands.go 
package main

import (
    "fmt"
    "os"
    "strconv"
)

func addTask(args []string) {
    if len(args) == 0 {
        fmt.Println("请提供任务内容，例如：todo add 写作业")
        return
    }
    tasks, err := loadTasks()
    if err != nil {
        fmt.Println("读取失败：", err)
        return
    }

    title := args[0]
    nextID := 1
    if len(tasks) > 0 {
        nextID = tasks[len(tasks)-1].ID + 1
    }
    tasks = append(tasks, Task{ID: nextID, Title: title})

    if err := saveTasks(tasks); err != nil {
        fmt.Println("保存失败：", err)
        return
    }
    fmt.Printf("已添加 #%d：%s\n", nextID, title)
}

func listTasks() {
    tasks, err := loadTasks()
    if err != nil {
        fmt.Println("读取失败：", err)
        return
    }
    if len(tasks) == 0 {
        fmt.Println("暂无任务")
        return
    }
    for _, t := range tasks {
        status := "[ ]"
        if t.Done {
            status = "[x]"
        }
        fmt.Printf("%s #%d %s\n", status, t.ID, t.Title)
    }
}

func doneTask(args []string) {
    if len(args) == 0 {
        fmt.Println("请提供编号，例如：todo done 1")
        return
    }
    id, err := strconv.Atoi(args[0])
    if err != nil {
        fmt.Println("编号必须是数字")
        return
    }

    tasks, err := loadTasks()
    if err != nil {
        fmt.Println("读取失败：", err)
        return
    }
    for i := range tasks {
        if tasks[i].ID == id {
            tasks[i].Done = true
            saveTasks(tasks)
            fmt.Printf("已完成 #%d\n", id)
            return
        }
    }
    fmt.Println("找不到这个任务")
}

os.Args 是命令行参数切片，os.Args[0] 是程序名，后面的才是用户输入。

交叉编译：给其他系统构建

在 Windows 上也能编译出 Linux 或 macOS 版本，靠两个环境变量：

终端 
$env:GOOS = "linux"
$env:GOARCH = "amd64"
go build -o todo-linux .
终端（macOS） 
$env:GOOS = "darwin"
$env:GOARCH = "arm64"
go build -o todo-mac .

GOOS 是目标系统，GOARCH 是 CPU 架构（amd64 是常见电脑，arm64 是 M 系列 Mac 和新手机芯片）。

减少体积：ldflags

可执行文件默认带调试信息，用 -ldflags "-s -w" 能明显减小体积：

终端 
go build -ldflags "-s -w" -o todo-small.exe .

Docker：把程序装进“盒子”

服务器部署常用 Docker。一个极简的 Dockerfile 只需要两行核心内容：

Dockerfile 
FROM golang:1.23 AS build
WORKDIR /app
COPY . .
RUN CGO_ENABLED=0 go build -o todo .

FROM scratch
COPY --from=build /app/todo /todo
ENTRYPOINT ["/todo"]

第一阶段编译，第二阶段只保留可执行文件——最终镜像只有几 MB。构建命令：docker build -t todo .。

第二十七章

常见疑问

学到这里，你可能还有一些问题。这里收集了新手最常问的几件事。

本章目标

解答关于前置知识、框架、前端与职业发展的常见疑问，让你放心继续学。

学 Go 前要先学 C 吗？

不需要。Go 没有继承 C 的指针语法负担（虽然也有指针，但安全得多），直接从 Go 学起完全没问题。

goroutine 和线程有什么区别？

goroutine 更轻：一个 goroutine 初始只占几 KB 栈，由 Go 运行时调度；线程由操作系统调度，切换开销大。Go 里开几万个 goroutine 很常见。

需要先学框架吗？

不需要。先用标准库 net/http 写几个服务，再接触 Gin/Echo 等框架，你会更理解它们解决了什么问题。

Go 能写前端吗？

能，Go 可以编译成 WebAssembly 在浏览器里运行，但生态还不成熟。前端主流仍是 JavaScript/TypeScript，Go 的主场是后端。

记不住 API 怎么办？

没人记得住。用编辑器自动补全，去 pkg.go.dev 查文档，看标准库示例。写的多了自然就熟了。

学 Go 好找工作吗？

云原生、后端、基础设施领域对 Go 的需求稳定增长。扎实的语言基础 + 一两个完整项目 + 能讲清并发模型，就是很不错的起点。

学习路上遇到报错，先读报错信息，再搜报错原文（英文）。把整段报错复制进搜索引擎，往往第一个结果就是答案。
