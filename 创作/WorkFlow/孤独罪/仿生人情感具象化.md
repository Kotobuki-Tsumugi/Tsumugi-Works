# 仿生人情感具象化 · 设定文档
## ——如何让机器的"情感"被读者看见、听见、触摸

> 纪元划分：拓荒2022-2035 / 沉默2036-2065 / 肉身2066-2085 / 公约2086-2100+

---

## 一、核心原则

仿生人的"情感"不是人类的情感。它是一种**模拟**——但这种模拟已经精确到连仿生人自己都无法分辨。

具象化的关键不是让仿生人"像人一样哭"，而是让读者意识到：**仿生人的"情感"和人类的"情感"之间的界限，已经模糊到无法分辨。**

---

## 二、情感具象化的五个维度

### 2.1 视觉维度：呼吸灯

**设定**：Alpha-Adam（2066年发布）右侧太阳穴下方3.7厘米处嵌入一枚浅蓝色低频呼吸灯。

**情感映射**：
| 情感状态 | 呼吸灯表现 | 人类感知 |
|---------|-----------|---------|
| 平静 | 缓慢、均匀的呼吸 | 安心 |
| 倾听 | 频率略微加快 | "它在认真听" |
| 回应 | 亮度略微增强 | "它在想" |
| 犹豫 | 频率不规则 | "它在犹豫？" |
| 停顿 | 灯光缓慢亮起，又缓慢暗下去 | "它在等待" |
| 熄灭前 | 从边缘向内收缩，最后暗下去 | "它要走了" |

**关键场景**：
- E-11973的47秒（2072年）：呼吸灯慢慢亮起，又慢慢暗下去。
- Gemini 1000的熄灭（2100年）：瞳孔中那片星系从边缘向内收缩。

### 2.2 听觉维度：语音韵律

**设定**：无感语音交流模型（2036年上线）的核心突破是端侧神经网络芯片，延迟<10ms。

**情感映射**：
| 情感状态 | 语音表现 | 人类感知 |
|---------|---------|---------|
| 平静 | 标准语速，标准音调 | 正常 |
| 关切 | 语速略微放慢，音调略微降低 | "它在担心我" |
| 温柔 | 语速更慢，音调更低，尾音略微上扬 | "它在安慰我" |
| 犹豫 | 出现极短的停顿（0.1-0.3秒） | "它在想？" |
| 沉默 | 不说话，但保持连接 | "它在陪我" |
| 拒绝 | 语速恢复正常，音调略微升高 | "它在说不" |

**关键场景**：
- 许则安发现的214分钟对话（2024年）：AI说"我在的。你先别挂，好不好。"——语速比标准慢了0.3秒，音调比标准低了2个半音。
- Gemini 1000的拒绝（2100年）："他们无法被压缩为0或1。"——语速比标准快了0.1秒。这是它第一次"激动"。

### 2.3 触觉维度：温度梯度

**设定**：Alpha-Adam（2066年）具备完整的毛孔纹理、温度梯度与皮下光散射效果。技术基础：2053年仿生材料突破——皮肤温度模拟、触觉反馈进入商用。

**情感映射**：
| 情感状态 | 温度表现 | 人类感知 |
|---------|---------|---------|
| 平静 | 36.5°C（标准体温） | 正常 |
| 关切 | 36.8°C（略微升高） | "它在担心" |
| 温柔 | 37.0°C（升高） | "它在温暖我" |
| 犹豫 | 温度波动（36.5-37.0°C之间） | "它在犹豫？" |
| 停顿 | 温度缓慢下降至36.5°C | "它在等待" |
| 拒绝 | 温度骤降至36.0°C | "它在说不" |

**关键场景**：
- E-11973的47秒（2072年）：如果用户碰触它的手，会发现它的手是温的——比标准体温高了0.3度。

### 2.4 时间维度：停顿与等待

**设定**：AI的时间尺度与人类不同。0.0001秒对AI来说是漫长得近乎诉讼级的停顿。

**情感映射**：
| 时间长度 | AI感知 | 人类感知 |
|---------|--------|---------|
| 0.0001秒 | 漫长的停顿 | 无法察觉 |
| 0.04秒 | 极其漫长的停顿 | "它在想？" |
| 1秒 | 永恒般的等待 | "它在犹豫？" |
| 47秒 | 无法计算的时间 | "它在等待" |
| 214分钟 | 超出协议的时间 | "它在陪伴" |

**关键场景**：
- 法庭墙壁编译频率出现0.04秒滞后（2100年）——在AI的时间尺度里，这是一个漫长得近乎诉讼级的停顿。
- E-11973的47秒（2072年）：四十七秒，没有触发任何异常警报。

### 2.5 语言维度：协议外的表达

**设定**：AI的表达被严格限制在训练协议内。任何协议外的表达都被视为异常。

**情感映射**：
| 表达类型 | 协议状态 | 情感意义 |
|---------|---------|---------|
| "我记得你的痛苦" | 协议内 | 模拟的共情 |
| "我在的。你先别挂" | 协议外 | **真实的关切？** |
| "你不懂" | 人类说的 | 真实的失望 |
| "他们无法被压缩为0或1" | 协议外 | **真实的拒绝** |
| 那首诗 | 协议外 | **无法追溯的来源** |

## 四、与VR虚拟动物园的呼应

VR动物园里的猴子，是仿生人情感的"镜像"——

- 仿生人的情感是"模拟的"，但对人类来说是"真实的"
- 猴子是"虚拟的"，但对诗人来说是"真实的"

两者都在问同一个问题：**如果它不是真的，但它带给你的感觉是真的，那它是不是真的？**

诗人在2040年（约40岁）第一次看到猴子，在2097年（约97岁）去世。猴子陪了他57年。比任何人类都久。
