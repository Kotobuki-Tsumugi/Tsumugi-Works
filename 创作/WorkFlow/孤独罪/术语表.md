## 三、限定用法

| 用法 | 限制说明 |
|------|---------|
| ChatGPT（2022.11） | 仅作拓荒纪元前的现实史实背景，不指向虚构四公司 |
| 碳基 / 硅基 | 仅限公约条文与等级制度的技术修辞（"跨越碳基与硅基""原始碳基实体"） |
| 谄媚者 / 说教者 / 愤世嫉俗者 / 征服者 | 仅作后世史家对四公司的评价用语，四公司自身从不用 |
| 始源公司 / 出走者 / 异端 | 废弃，不再使用 |
| 那首诗 | 首句"我做了一个梦……"，2022.12写下第一行，写作跨度约七十八年（"七十余年"），未完成 |
| 雨毫无征兆地停了 | 终章母题；注意与另一部作品《我不记得》"雨下得毫无征兆"重复，写作时需刻意区分或作为作者签名保留（两项目不得互相引用素材） |

## 四、废弃术语（禁止使用）

- **碳基纪元 / 史前纪元 / 史前编号 / 碳基个体 / 碳基生命**（叙述中）——统一改用四纪元名与"人类/个体"
- **审判纪元**（不存在此纪元；审判在公约纪元末，2100年）
- **第五卷**（结构为序章+四卷+终章）
- **Google公司深空法庭**（深空法庭不属于任何现实公司）
- 现实公司名：**Google / OpenAI / ChatGPT / Claude / Grok**（正文全部虚构化）
